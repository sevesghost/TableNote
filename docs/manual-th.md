# คู่มือใช้งาน ตารางโน้ต (TableNote) 2.6.0

ตารางโน้ตเป็นโปรแกรมจดงานแบบตารางคล้าย Excel ที่เตือนเมื่องานถึงกำหนดส่ง และเตือนล่วงหน้าได้

---

## 1. เริ่มต้นใช้งาน

1. ดับเบิลคลิก `TableNote.exe` แล้วจะเห็นตารางสีเหลืองอ่อนที่มี 4 คอลัมน์ คือ **หัวข้อ, รายละเอียด, สถานะ, กำหนดส่ง** หน้าต่างโปรแกรมเป็นภาษาอังกฤษเป็นค่าเริ่มต้น สลับเป็นไทยได้ที่เมนู **View → Language** (มุมมอง → ภาษา, ดูข้อ 11)
2. คลิกช่องไหนก็พิมพ์ได้เลย โปรแกรม **บันทึกให้อัตโนมัติ** หลังหยุดพิมพ์ประมาณ 1.5 วินาที ไม่ต้องกดบันทึกเอง
3. เปิดโปรแกรมได้ทีละหน้าต่างเดียว ถ้ากดเปิดซ้ำ ระบบจะใช้หน้าต่างเดิม
4. ตอนแก้ไขตาราง โปรแกรมจะมีไอคอนบนแถบงาน (taskbar) และไอคอน **ตารางโน้ต** ในถาดระบบที่มุมจอ ในโหมดวอลเปเปอร์ (ข้อ 8) จะเหลือไอคอนที่ถาดอย่างเดียว
5. แถบเครื่องมือมีแถวเดียว เฉพาะปุ่มที่ใช้บ่อย: **+ แถว**, **− แถว**, **+ คอลัมน์**, **สี**, **ซ่อนงานเสร็จ**, **เรียงตามกำหนด**, **A−** / **100%** / **A+**, **ส่งออก** และ **วอลเปเปอร์** ที่เหลืออยู่ในแถบเมนู: **ไฟล์** (คัดลอก ส่งออก ส่งออกภาพ พิมพ์ ตั้งเป็นวอลเปเปอร์), **ตาราง** (สี แถว คอลัมน์ เรียง เพิ่มกล่องแจ้งเตือน), **คอลัมน์**, **แถว**, **มุมมอง** (ซ่อนงานเสร็จ เรียง ขยาย/ย่อ ภาษา และ **ตั้งค่าระบบ**: โหมดลอย ล็อกตำแหน่ง เปิดเมื่อเข้าสู่ระบบ ปิดเสียงเตือน) และ **ช่วยเหลือ** (วิธีใช้ Log)

> **การเตือนทำงานเมื่อโปรแกรมทำงานอยู่**
>
> - กดปิดหน้าต่างหลัก (X) โปรแกรม **ไม่ปิด** แต่จะย่อไปอยู่ที่ถาดไอคอน และยังเตือนต่อ ครั้งแรกจะมีข้อความบอก
> - ถ้าไม่มีไอคอน ตารางโน้ต ในถาด (เช่น ระบบสร้างไอคอนไม่ได้) การกด X จะปิดโปรแกรมจริง และจะไม่เตือนจนกว่าจะเปิดใหม่
> - เปิดหน้าต่างกลับได้ด้วยการคลิกไอคอนในถาด หรือเลือก **แก้ไขตาราง**
> - ถ้าจะออกจริง ให้เลือก **ไฟล์ → ออกจากโปรแกรม** หรือคลิกขวาไอคอนในถาดแล้วเลือก **ออก** โปรแกรมจะไม่เตือนจนกว่าจะเปิดใหม่ (**ไฟล์ → ปิดหน้าต่าง** ทำเหมือนกด X)

**แถบการทำงาน (2.6.0)** แถบเล็ก ๆ ล่างสุดของหน้าต่างบอกว่าตารางโน้ตกำลังทำอะไร มีหลอดความคืบหน้าวิ่งตอนส่งออก บันทึกภาพ เตรียมหน้าพิมพ์ หรือวาดวอลเปเปอร์ หลังแก้ไขจะขึ้น "รอบันทึกอัตโนมัติ…" นอกนั้นแสดงสิ่งที่ทำล่าสุดพร้อมเวลา และเวลาที่บันทึก note.json ล่าสุด จุดสีเขียว = ปกติ เหลือง = กำลังทำงาน ส้ม = มีเรื่องควรรู้ (เช่น "โปรแกรมไม่ตอบสนอง 3.2 วินาที ขณะบันทึก note.json") แดง = ทำไม่สำเร็จ ปุ่ม **ประวัติ** แสดงสิ่งที่ทำล่าสุดจากใหม่ไปเก่า และปุ่ม **เปิดโฟลเดอร์** เปิดโฟลเดอร์ที่มี `tablenote.log` กด **✕** เพื่อซ่อนแถบ เปิดคืนได้ที่ **มุมมอง → แถบการทำงาน**
> - แนะนำให้เปิด **มุมมอง → ตั้งค่าระบบ → เปิดเมื่อเข้าสู่ระบบ** โปรแกรมจะเปิดเองแบบซ่อนอยู่ในถาดทุกครั้งที่เข้าเครื่อง ถ้าครั้งล่าสุดใช้โหมดวอลเปเปอร์ไว้ จะวาดตารางบนวอลเปเปอร์ให้ใหม่แทน
> - ดูวิธีใช้ในโปรแกรมได้จากเมนู **ช่วยเหลือ → วิธีใช้** หรือเมนู **วิธีใช้** ในถาด

## 2. เพิ่มงาน

| ทำอะไร | ปุ่มหรือเมนู | ปุ่มลัด |
|---|---|---|
| เพิ่มแถว | `+ แถว` | F5 |
| ลบแถว (ถ้ามีข้อความจะถามก่อน) | `− แถว` | F6 |
| เพิ่มคอลัมน์ | `+ คอลัมน์` | F7 |
| ลบคอลัมน์ (ถ้ามีข้อความจะถามก่อน, คอลัมน์กำหนดส่งลบไม่ได้) | **ตาราง → − คอลัมน์** | F8 |

**การใช้ช่องในตาราง (แบบ Excel, 2.6.0)**
- คลิกที่ช่อง = **เลือก** ช่องนั้น ช่องเป็นสีทอง และแถบสูตรเหนือตารางแสดงที่อยู่ช่อง (เช่น B3) กับข้อความทั้งหมด ถ้าพิมพ์เลย จะ **เขียนทับ** ข้อความเดิม ถ้าจะแก้ข้อความเดิมให้ **ดับเบิลคลิก** หรือกด **F2** เคอร์เซอร์จะอยู่ท้ายข้อความ กด **Esc** เพื่อคืนค่าเดิม **Enter** เพื่อบันทึกแล้วลงไปช่องข้างล่าง **Tab** เพื่อไปช่องทางขวา
- **ลาก** ผ่านหลายช่อง (หรือ Shift+คลิก, Shift+ลูกศร) เพื่อคลุมหลายช่อง กด **Delete** ล้าง **Ctrl+C** คัดลอก **Ctrl+X** ตัด **Ctrl+V** วาง กด **Ctrl+A** หรือคลิกมุมซ้ายบนของตารางเพื่อเลือกทุกช่อง คลิกที่ว่างเพื่อยกเลิกการเลือก คลิกขวาที่ช่องก็มีคำสั่งเหล่านี้
- **แถบสูตร** ไว้อ่านและแก้ข้อความยาว คลิกที่แถบ แก้ข้อความ แล้วกด Enter (Esc = คืนค่าเดิม, Alt+Enter = ขึ้นบรรทัดใหม่) แถบนี้ไม่คำนวณสูตร
- **Ctrl+F** (หรือ **ตาราง → ค้นหา…**) ค้นหาข้อความ ทุกช่องที่เจอเป็นสีเหลือง ช่องปัจจุบันจะถูกเลือก กด Enter / Shift+Enter (หรือ F3 / Shift+F3) ไปช่องถัดไป / ก่อนหน้า กด Esc เพื่อปิดแถบค้นหา

**เลือกทั้งแถวและทั้งคอลัมน์ (2.6.0)**
- คลิก **เลขแถว** เพื่อเลือกทั้งแถว หรือคลิก **หัวคอลัมน์** เพื่อเลือกทั้งคอลัมน์ ลากไปตามเลขแถวหรือหัวคอลัมน์ หรือกด Shift+คลิก เพื่อเลือกหลายอัน
- **คลิกขวา** ที่เลขแถวที่เลือก: **แทรก N แถวด้านบน / ด้านล่าง**, **ลบ N แถว**, **แทรกแถวที่คัดลอก** ที่หัวคอลัมน์: **แทรก N คอลัมน์ทางซ้าย / ขวา**, **ลบ N คอลัมน์**, **แทรกคอลัมน์ที่คัดลอก** ที่ช่อง: **แทรก ▸** และ **ลบ ▸** แถวหรือคอลัมน์ของช่องนั้น และ **แทรกเซลล์ที่คัดลอก** N คือจำนวนที่เลือกไว้ ถ้ามีข้อมูลจะถามก่อนลบ ส่วน F6 และ F8 ลบทุกแถวหรือคอลัมน์ที่เลือก
- **แทรกที่คัดลอก**: คัดลอกทั้งแถว (หรือทั้งคอลัมน์) ด้วย Ctrl+C เลือกตำแหน่งที่จะแทรก แล้วคลิกขวา → แทรกที่คัดลอก แถวจะมาพร้อมสีแถว ไฮไลต์ การทำซ้ำ และการเตือนล่วงหน้า คอลัมน์มาพร้อมชื่อ ชนิด ตัวเลือก และความกว้าง คอลัมน์สถานะหรือกำหนดส่งที่คัดลอกจะเป็นคอลัมน์ข้อความธรรมดา (ตารางยังมีอย่างละอันเดียว) ข้อความที่คัดลอกจาก Excel จะแทรกเป็นแถวใหม่
- **ย้ายแถว**: ลากที่จับ **⋮⋮** จาง ๆ ทางซ้ายของเลขแถว ถ้าเลือกไว้หลายแถว จะย้ายไปพร้อมกัน
- **เปลี่ยนชื่อคอลัมน์**: ดับเบิลคลิกที่หัวคอลัมน์ (หรือเลือกแล้วกด F2) พิมพ์ชื่อ แล้วกด Enter กด Esc ถ้าจะใช้ชื่อเดิม

ขั้นตอน
1. กด **+ แถว** หรือ F5
2. ใส่ **หัวข้อ** ซึ่งเป็นชื่อที่จะขึ้นในหน้าต่างเตือน และใส่ **รายละเอียด** ถ้ามี
3. เลือก **สถานะ** จากรายการ ซึ่งมี 3 ค่า คือ `ยังไม่เริ่ม`, `กำลังทำ`, `เสร็จแล้ว`
4. ตั้ง **กำหนดส่ง** และเลือกว่าจะให้ **ทำซ้ำ** หรือไม่ (ดูหัวข้อถัดไป)

ถ้าพิมพ์สถานะเองหรือวางมาจาก Excel จะนับว่าเสร็จเฉพาะคำเหล่านี้แบบตรงทั้งคำ คือ `เสร็จ`, `เสร็จแล้ว`, `done`, `complete`, `completed`, `✓`, `✔` (ตัวพิมพ์เล็กหรือใหญ่ก็ได้) ใช้เหมือนกันทุกจุด ทั้งการเตือน สี และการซ่อนงานเสร็จ

คำว่า `ยังไม่เสร็จ`, `ไม่เสร็จ` หรือ `เสร็จไม่ทัน` **ไม่นับว่าเสร็จ** งานนั้นจะยังเตือนตามปกติ

โปรแกรมเก็บสถานะในไฟล์เป็นรหัสที่ไม่ขึ้นกับภาษา คือ `todo` (ยังไม่เริ่ม), `doing` (กำลังทำ) และ `done` (เสร็จแล้ว) แล้วแปลเฉพาะตอนแสดงผล ดังนั้นการสลับภาษาจะไม่เปลี่ยนข้อมูลหรือสถานะของงาน
- เมื่อเปิดไฟล์รุ่นเก่า จะแปลงเฉพาะป้ายมาตรฐาน: `ยังไม่เริ่ม`, `ยังไม่เสร็จ` และ `todo` เป็น `todo`; `กำลังทำ` เป็น `doing`; และ `เสร็จ`, `เสร็จแล้ว`, `done` และ `complete` เป็น `done` คำอื่น เช่น `completed`, `✓` และ `✔` เก็บตามที่พิมพ์ไว้ แต่ยังนับว่าเสร็จ
- สถานะที่พิมพ์เองจะเก็บตรงตามที่พิมพ์ นับว่าเสร็จเฉพาะเมื่อตรงกับคำที่ระบุข้างต้น (ตัวพิมพ์เล็กหรือใหญ่ก็ได้)

ช่องสถานะที่ว่างจะถูกบันทึกว่างไว้ แสดงเป็น `ยังไม่เริ่ม` (หรือ `Not started` ในภาษาอังกฤษ) และนับว่ายังไม่เสร็จ โปรแกรมจะไม่เติมค่าให้เอง

เปลี่ยนชื่อหัวคอลัมน์ได้ทุกคอลัมน์ รวมทั้ง "สถานะ" และ "กำหนดส่ง" เพราะโปรแกรมจำหน้าที่ของคอลัมน์ไว้ ไม่ได้ดูจากชื่อ คอลัมน์กำหนดส่ง **ลบไม่ได้** เพราะการเตือนใช้คอลัมน์นี้ ถ้ากดลบจะมีข้อความแจ้ง ถ้าไฟล์ไม่มีคอลัมน์กำหนดส่ง จะขึ้นข้อความแจ้งทันทีว่าการแจ้งเตือนจะไม่ทำงาน

ตารางมีได้ไม่เกิน 1,000 แถว (เพิ่มจาก 200 แถวในรุ่น 2.3.0) และ 30 คอลัมน์ที่ผู้ใช้เพิ่มเอง โดยคอลัมน์ของระบบอาจเพิ่มได้อีกเล็กน้อย ช่องละไม่เกิน 2,000 ตัวอักษร

## 3. ตั้งวันครบกำหนดและงานทำซ้ำ

ในช่อง **กำหนดส่ง** มี 5 ส่วนเรียงกัน

1. **ช่องวัน** คลิกแล้วเลือกวันจากปฏิทิน
2. **ช่องเวลา** พิมพ์เวลาแบบ `HH:mm` เช่น `14:30` ถ้าไม่ใส่จะเป็น `09:00`
3. **ช่องทำซ้ำ** เลือก `ไม่ซ้ำ`, `ทุกวัน`, `ทุกสัปดาห์` หรือ `ทุกเดือน` งานที่ตั้งทำซ้ำจะมีรูป 🔁 อยู่หน้าช่อง
4. **ปุ่ม 📅**
   - คลิก ถ้าช่องมีวันอยู่แล้ว จะเปิดปฏิทินให้เลือก ถ้าช่องยังว่าง จะตั้งเป็นอีก 1 นาทีจากตอนนี้ทันที (ไม่เปิดปฏิทิน) ใช้ทดสอบว่าการเตือนทำงานไหม
   - กด Shift ค้างไว้แล้วคลิก จะตั้งเป็นพรุ่งนี้ 09:00
5. **ปุ่ม ⏰** ตั้งเตือนล่วงหน้า (ดูข้อ 3.1) ถ้าตั้งไว้แล้วจะมีตัวเลขบอกจำนวน เช่น ⏰2

ถ้ามีรูป ⚠ หน้าช่อง แปลว่าโปรแกรมอ่านกำหนดส่งในช่องนั้นไม่ได้ งานนั้นจะไม่เตือน ให้ตั้งวันใหม่จากปฏิทิน

### 3.1 เตือนล่วงหน้า ⏰

1. กดปุ่ม ⏰ ในช่องกำหนดส่งของงานนั้น
2. ติ๊ก **ก่อน 15 นาที**, **ก่อน 1 ชั่วโมง**, **ก่อน 1 วัน** หรือใส่ **กำหนดเอง** เป็นตัวเลขแล้วเลือกหน่วย นาที / ชั่วโมง / วัน แล้วกด **เพิ่ม**
3. กด **บันทึก**

ข้อควรรู้
- ตั้งได้สูงสุด **5 ครั้งต่องาน** ถ้าใส่ค่าซ้ำจะนับเป็นครั้งเดียว และเตือนล่วงหน้าได้ไม่เกิน 30 วัน
- **การเตือนตรงเวลายังมีเสมอ** ไม่ต้องตั้งเพิ่ม
- เวลาเตือนที่เลยมาแล้วตอนที่ตั้งค่า จะข้ามไป ไม่เด้งขึ้นทันที เช่น ตั้งก่อน 1 วันให้งานที่ส่งในอีก 2 ชั่วโมง
- งานที่เลยกำหนดไปแล้ว (เช่น ตอนเปิดเครื่องมา) จะเตือนแค่ **ครบกำหนดแล้ว** ไม่เด้งเตือนล่วงหน้าที่พลาดไป
- งานทำซ้ำ รอบถัดไปจะได้ค่าเตือนล่วงหน้าเดิมไปด้วย
- ถ้าตั้งเตือนล่วงหน้าผิด กด Ctrl+Z ย้อนได้
- การแก้ค่าเตือนล่วงหน้า (แม้กดบันทึกโดยไม่เปลี่ยนอะไร) **ไม่ล้างการรับทราบเดิม** งานที่กดรับทราบไว้แล้วจะไม่เด้งซ้ำ การรับทราบจะล้างเมื่อแก้กำหนดส่ง หรือเมื่อเปลี่ยนงานที่ `เสร็จแล้ว` กลับเป็นยังไม่เสร็จ (คำนวณการเตือนใหม่จากตอนนั้น ไม่เด้งเตือนล่วงหน้าที่เลยมาแล้ว แต่ถ้าเลยกำหนดส่งแล้วจะเตือนครบกำหนด)

**งานทำซ้ำทำงานแบบนี้** เมื่อเปลี่ยนสถานะเป็น `เสร็จแล้ว` ไม่ว่าจะจากรายการสถานะหรือจากปุ่มในหน้าต่างเตือน แถวเดิมจะเก็บไว้เป็นประวัติ และโปรแกรมจะแทรกแถวรอบถัดไปไว้ข้างล่าง โดยมีสถานะเป็น `ยังไม่เริ่ม`
- `ทุกเดือน` ถ้าเดือนถัดไปไม่มีวันนั้น จะใช้วันสุดท้ายของเดือนแทน แล้วกลับมาใช้วันเดิมในเดือนที่มีวันนั้น เช่น 31 ม.ค. → 28 ก.พ. → 31 มี.ค.
- ถ้ากำหนดส่งมีแต่วันที่ ไม่มีเวลา รอบถัดไปก็จะมีแต่วันที่เหมือนกัน
- เปลี่ยนค่าทำซ้ำแล้ว รูป 🔁 จะขึ้นหรือหายทันที และกด Ctrl+Z ย้อนได้
- ค่าทำซ้ำถูกเก็บในไฟล์เป็นรหัสเช่นเดียวกับสถานะ เมื่อเปิดไฟล์ ทั้งค่าภาษาไทยเดิมและป้ายภาษาอังกฤษจะถูกแปลงเป็นรหัส ดังนั้นการสลับภาษาจะไม่เปลี่ยนค่านี้
- การวางข้อมูลจาก Excel จะไม่สร้างรอบถัดไป
- ถ้าตารางครบ 1,000 แถวแล้ว จะสร้างรอบถัดไปไม่ได้ และมีข้อความแจ้ง

**ถ้าวางวันที่มาจาก Excel** โปรแกรมอ่านได้หลายแบบ เช่น `2026-11-20 14:30`, `20/11/2026 14:30`, `5/1/2026 9:00` หรือ `2026-11-20` โดยอ่านเป็น **วัน/เดือน/ปี** เสมอ (`5/1/2026 9:00` คือ 5 มกราคม 2026 เวลา 09:00) ไม่ว่าเครื่องจะตั้งภาษาหรือปฏิทินแบบไหน ชั่วโมงหลักเดียวหรือมีวินาทีก็ได้ ถ้าไม่มีเวลา จะถือเป็น 00:00 และถ้าใส่ปี พ.ศ. เช่น `09/11/2569` โปรแกรมจะแปลงเป็น ค.ศ. 2026 ให้เอง วันที่ที่มีชื่อเดือน (`5 Jan 2026`, `5 ม.ค. 2569`) และปีสองหลัก (`5/1/26`) ก็อ่านได้ ปีสองหลักจะถือเป็นปี ค.ศ. หรือ พ.ศ. ที่ใกล้วันนี้ที่สุด

ถ้าแก้กำหนดส่งด้วยปฏิทิน ช่องเวลา หรือปุ่ม 📅 การเลื่อนเตือนและการรับทราบเดิมของงานนั้นจะถูกยกเลิก แล้วจะคำนวณเวลาเตือนใหม่ทันที (ทั้งเตือนล่วงหน้าและตรงเวลา)

ปุ่ม **เรียงตามกำหนด** จะเรียงงานที่ใกล้กำหนดที่สุดขึ้นก่อน งานที่ไม่มีกำหนดส่งจะไปอยู่ท้ายตาราง

## 4. เมื่อมีเตือนต้องทำอะไร

โปรแกรมเช็กงานทุกประมาณ 30 วินาที จึงจะเตือนภายในราวครึ่งนาทีหลังถึงเวลาที่ตั้งไว้ งานที่ `เสร็จแล้ว` จะไม่เตือน

เมื่อถึงเวลา จะมี **เสียงแจ้งเตือนของ Windows** และหน้าต่างสีเหลืองขึ้นมาบนสุด หน้าต่างนี้ **ไม่แย่งโฟกัส** จึงพิมพ์งานที่ทำอยู่ต่อได้ ถ้ามีหลายงานถึงเวลาพร้อมกัน จะรวมไว้ในหน้าต่างเดียวที่แสดงเป็นรายการ จากรุ่น 2.3.0 จะมีหน้าต่างเตือนเพียงหน้าต่างเดียว: ถ้ามีเตือนเข้ามาขณะหน้าต่างเปิดอยู่ จะถูกเพิ่มเข้าไปในรายการ ไม่เปิดหน้าต่างใหม่

แต่ละงานจะบอกว่าเป็นการเตือนแบบไหน
- **⏰ อีก 15 นาทีครบกำหนด** (หรือ 1 ชั่วโมง, 1 วัน ฯลฯ) คือเตือนล่วงหน้า
  - ถ้าเด้งช้า เช่น เพิ่งเปิดโปรแกรม จะบอกเวลาที่เหลือจริง เช่น **อีก 7 นาทีครบกำหนด — พลาดการเตือนเมื่อ …**
  - ถ้าเปิดหน้าต่างเตือนล่วงหน้าค้างไว้จนถึงกำหนดส่ง ข้อความจะเปลี่ยนเป็น **ครบกำหนดแล้ว** และมีเสียงอีกครั้ง ปุ่มต่างๆ จะมีผลกับการเตือนครบกำหนด
- **🔔 ครบกำหนดแล้ว** คือเตือนตรงเวลา ถ้าเลยมานานจะบอกว่า "พลาดการเตือนเมื่อ ..."
- ถ้างานเดียวถึงเวลาเตือนหลายครั้งพร้อมกัน จะขึ้นแค่รายการเดียว โดยใช้เวลาที่ใกล้กำหนดส่งที่สุด

แต่ละงานในหน้าต่างเตือนมีปุ่มของตัวเอง

| ปุ่ม | ผลที่ได้ |
|---|---|
| **เลื่อน 10 นาที** | เลื่อนเฉพาะการเตือนครั้งนั้นของงานนั้น แล้วอีก 10 นาทีจะเตือนใหม่ ถึงจะปิดแล้วเปิดโปรแกรมใหม่ โปรแกรมก็ยังจำเวลาเลื่อนไว้ ถ้าเลื่อนเตือนล่วงหน้าแล้วเลยกำหนดส่ง จะรวมไปเตือนตอนครบกำหนดแทน |
| **เสร็จแล้ว** | เปลี่ยนสถานะงานนั้นเป็น `เสร็จแล้ว` และหยุดเตือน ถ้าตั้งทำซ้ำไว้ จะสร้างแถวรอบถัดไปให้ |
| **รับทราบ** | ไม่เตือนซ้ำสำหรับเวลาเตือนนี้ (และเวลาเตือนล่วงหน้าที่มาก่อน) เฉพาะงานนั้น ถ้ายังมีเตือนตรงเวลาอยู่ จะยังเตือนตอนครบกำหนด |

ด้านล่างของหน้าต่างมีปุ่มสำหรับทุกงานที่ยังค้างอยู่ ซึ่ง **ทำงานไม่เหมือนกัน** ต้องเลือกให้ถูก

| ปุ่ม | ผลที่ได้ |
|---|---|
| **ปิด (รับทราบทั้งหมด)** (ถ้ามีงานเดียวจะเขียนว่า **ปิด (รับทราบ — ไม่เตือนซ้ำเวลานี้)**) | **รับทราบ** ทุกงานที่ยังค้างในหน้าต่าง เหมือนกด รับทราบ ทีละงาน |
| **X** มุมขวาบนของหน้าต่าง | **เลื่อน 10 นาที** งานที่ยังค้างจะเตือนอีกครั้งใน 10 นาที |

> ถ้ายังไม่ได้ทำงานนั้นและอยากให้เตือนอีก ให้กด **X** หรือ **เลื่อน 10 นาที** อย่ากด **ปิด** หรือ **รับทราบ** ที่การเตือนตรงเวลา เพราะจะไม่เตือนอีกเลยจนกว่าจะแก้กำหนดส่ง
>
> ถ้าเปลี่ยนงานเป็น `เสร็จแล้ว` ในตารางระหว่างที่หน้าต่างเตือนเปิดอยู่ งานนั้นจะหายจากหน้าต่างเตือนภายในไม่กี่วินาที

ถ้าไม่อยากได้ยินเสียง ให้เลือก **มุมมอง → ตั้งค่าระบบ → ปิดเสียงเตือน** หน้าต่างเตือนยังขึ้นเหมือนเดิม

หน้าต่างเตือนสีเหลืองจะขึ้นเสมอ แม้ Windows จะปิดการแจ้งเตือนไว้ (เช่น โหมดโฟกัส)

**เสียงแจ้งเตือน** (2.6.0): **มุมมอง → ตั้งค่าระบบ → เสียงแจ้งเตือน…** ตั้งเสียงและความดัง เลือกเสียงเตือนของ Windows (แบบเดิม) เสียงอื่นของ Windows (ปฏิทิน นาฬิกาปลุก 1–10 เสียงเรียก 1–6 กระดิ่ง ฯลฯ) หรือไฟล์ .wav ของเองด้วย **เลือกไฟล์ .wav…** เลื่อนแถบความดัง (เริ่มต้น 50%) แล้วกด **▶ ทดลองเสียง** เพื่อฟัง ถ้าตั้งเกิน 50% โปรแกรมจะถามว่าแน่ใจหรือเปล่า เพราะเสียงดังอาจทำให้คนรอบข้างตกใจ ตอบ **ไม่** จะกลับไป 50% ติ๊ก **ปิดเสียงเตือน** ถ้าไม่ต้องการเสียง (หน้าต่างเตือนยังขึ้นตามปกติ)

## 5. ความหมายของสี

| สีแถว | ความหมาย |
|---|---|
| **แดงอ่อน** | เลยกำหนดส่งแล้ว |
| **เหลืองเข้ม** | ครบกำหนดวันนี้ แต่ยังไม่ถึงเวลา |
| **เทาจาง** มีเส้นขีดฆ่า และตัวหนังสือจาง | งานเสร็จแล้ว |
| เหลืองอ่อนปกติ | ยังไม่ถึงกำหนด หรือไม่ได้ใส่กำหนดส่ง |

ติ๊ก **ซ่อนงานเสร็จ** เพื่อซ่อนแถวที่เสร็จแล้ว และเอาติ๊กออกเพื่อให้กลับมาแสดง

## 6. วางจาก Excel และคัดลอกออก

- **วางจาก Excel** ให้คัดลอกช่วงตารางจาก Excel หรือ Google Sheets มา แล้วคลิกช่องที่จะเริ่มวาง จากนั้นกด Ctrl+V ข้อมูลจะกระจายลงหลายช่องให้เอง และวางได้ไม่เกิน 256 KB ต่อครั้ง ข้อมูลที่วางเป็นข้อความล้วน สูตรจะไม่ถูกคำนวณ ถ้าติ๊ก **ซ่อนงานเสร็จ** อยู่ ข้อมูลที่วางจะลงเฉพาะแถวที่มองเห็น ข้ามงานเสร็จที่ซ่อนอยู่
- **คัดลอกตาราง** คัดลอกทุกช่องโดยไม่เอาหัวคอลัมน์
- **คัดลอกพร้อมหัว** คัดลอกทั้งตาราง โดยแถวแรกเป็นหัวคอลัมน์
- **Ctrl+C** คัดลอกเฉพาะช่องที่เลือกอยู่ (ลากหรือ Shift+คลิกเพื่อเลือกหลายช่อง Ctrl+A เพื่อเลือกทั้งหมด) สถานะจะคัดลอกเป็นข้อความที่เห็น
- **Ctrl+V** ตอนเลือกช่องเดียว จะวางเริ่มที่ช่องนั้น ถ้าคัดลอกมาแค่ค่าเดียว จะเติมลงทุกช่องที่เลือก
- ข้อมูลที่คัดลอกจะเป็นข้อความล้วน เอาไปวางใน Excel ได้เลย

## 7. ย้อนกลับ

กด **Ctrl+Z** เพื่อย้อน และกด **Ctrl+Y** หรือ **Ctrl+Shift+Z** เพื่อทำซ้ำ หรือใช้เมนู **ตาราง → ย้อนกลับ / ทำซ้ำ** ซึ่งบอกด้วยว่าจะย้อนอะไร ("ย้อนกลับ: ลบแถว") เก็บไว้ได้สูงสุด 100 ขั้น

ย้อนได้ทีละ 1 ขั้น สำหรับ
- การพิมพ์ในช่อง (นับ 1 ขั้นต่อการแก้ 1 ครั้ง เมื่อกด Enter หรือคลิกออกจากช่อง)
- การแก้หัวคอลัมน์
- การวางจาก Excel (ทั้งก้อนนับเป็น 1 ขั้น)
- การเพิ่มหรือลบแถวและคอลัมน์ (F5–F8) รวมถึงทีละหลายอัน และแทรกที่คัดลอก จากเมนูไหนก็ได้
- การย้ายคอลัมน์หรือแถว
- การตั้งค่าคอลัมน์ และสีหรือไฮไลต์แถว
- การเปลี่ยนสถานะ รวมถึงการกด **เสร็จแล้ว** ที่สร้างรอบถัดไป (นับเป็นขั้นเดียว)
- การตั้งกำหนดส่ง ค่าทำซ้ำ และค่าเตือนล่วงหน้า

**ระหว่างที่กำลังพิมพ์อยู่ในช่อง** Ctrl+Z จะย้อนตัวอักษรในช่องนั้นก่อน เมื่อออกจากช่องแล้ว Ctrl+Z จะย้อนทั้งการแก้นั้น

การย้อนจะผูกกับแถว ไม่ใช่ลำดับแถว จึงใช้ได้ถูกต้องแม้กด **เรียงตามกำหนด** ไปแล้ว

**ไม่ย้อน** ได้แก่ การเลื่อนเตือน การรับทราบ การซ่อนงานเสร็จ การปิดเสียง และตำแหน่งหน้าต่าง

## 8. รูปแบบหน้าต่างและโหมดวอลเปเปอร์

- **โหมดลอย** (มุมมอง → ตั้งค่าระบบ) ทำให้หน้าต่างอยู่บนสุดเสมอ
- **ล็อกตำแหน่ง** (มุมมอง → ตั้งค่าระบบ) ทำให้ลากหน้าต่างไม่ได้ ถ้าจะย้ายให้ปลดล็อกก่อน
- **วอลเปเปอร์** (ปุ่มบนแถบเครื่องมือ หรือ ไฟล์ → ตั้งเป็นวอลเปเปอร์ ใช้ได้บน Windows) ตั้งตารางเป็นวอลเปเปอร์แบบเต็มจอ วอลเปเปอร์เดิมของคุณยังอยู่ และมีการ์ดที่มีกล่องแจ้งเตือนกับตารางวางทับตรงตำแหน่งที่หน้าต่างอยู่ ขนาดไม่เกินหน้าต่าง (แถวที่ไม่พอแสดงเป็น "+ อีก N แถว") เปลี่ยนเฉพาะจอที่หน้าต่างอยู่ หน้าแก้ไขไปอยู่ที่ถาด และภาพจะวาดใหม่เมื่อตารางเปลี่ยน เมื่องานเลยกำหนดหรือครบกำหนดวันนี้ และเมื่อขึ้นวันใหม่ ใช้แทน วางแนบพื้นหลัง ของรุ่นก่อน

**กลับมาแก้ไขจากโหมดวอลเปเปอร์ได้ 5 วิธี** (วอลเปเปอร์เดิมจะกลับมาทันที)
1. คลิกไอคอน **ตารางโน้ต** ในถาดมุมจอ
2. คลิกขวาไอคอนแล้วเลือก **แก้ไขตาราง**
3. กด **Ctrl+Shift+E**
4. เปิดโปรแกรมซ้ำอีกครั้ง
5. เปิดด้วยคำสั่ง `TableNote.exe --edit`

- เลือก **ออก** ในเมนูถาดก็คืนวอลเปเปอร์เดิมเหมือนกัน แต่โหมดวอลเปเปอร์ยังจำไว้ เปิดครั้งหน้าจะวาดตารางกลับมา ถ้าออกจากระบบตอนเปิด **เปิดเมื่อเข้าสู่ระบบ** ไว้ ตารางจะยังอยู่บนวอลเปเปอร์และวาดใหม่ตอนเข้าระบบ ถ้าไม่ได้เปิดไว้ จะคืนวอลเปเปอร์เดิม
- สไลด์โชว์จะเริ่มใหม่ตอนออกจากโหมดวอลเปเปอร์ ส่วน **Windows spotlight** โปรแกรมเปิดกลับเองไม่ได้ จึงถามก่อน และตอนออกจะเหลือภาพ spotlight ของวันนั้นเป็นภาพนิ่ง (เปิด spotlight ใหม่ได้ที่ การตั้งค่า › การปรับแต่งให้เป็นแบบส่วนตัว › พื้นหลัง)
- ถ้าเปลี่ยนวอลเปเปอร์เองระหว่างนั้น โปรแกรมจะใช้ภาพที่คุณเลือก วอลเปเปอร์ที่องค์กรกำหนดไว้จะไม่ถูกเปลี่ยน
- ก่อนเปลี่ยนอะไร โปรแกรมเก็บสำเนาวอลเปเปอร์เดิมไว้ที่ `%LOCALAPPDATA%\TableNote\wallpaper\` จึงคืนได้แม้โปรแกรมปิดตัวผิดปกติ

เมนูในถาดมี **แก้ไขตาราง**, **วิธีใช้**, **Log**, **ส่งออก…**, **ภาษา**, ขยาย/ย่อ, **ย้ายกลับกลางจอ** และ **ออก** ถ้าหน้าต่างหลุดไปนอกจอ ให้เลือก **ย้ายกลับกลางจอ** การปิดหน้าต่างหลักจะย่อไปที่ถาด การออกจากโปรแกรมจริงทำได้จากเมนู **ออก** เท่านั้น

## 10. คำถามที่พบบ่อย

**ข้อมูลเก็บที่ไหน**
- บน Windows อยู่ที่ `%APPDATA%\TableNote\note.json` ถ้าจะเปิดดู ให้พิมพ์ `%APPDATA%\TableNote` ในช่องที่อยู่ของ File Explorer
- บน Linux อยู่ที่ `~/.local/share/TableNote/note.json`
- ถ้าเอาเมาส์ไปวางที่แถบสถานะล่างหน้าต่าง จะเห็นที่อยู่ไฟล์จริง

**เอาไฟล์จากรุ่นเก่ามาใช้ได้ไหม**
ได้ครับ โปรแกรมจะเพิ่มคอลัมน์สถานะและกำหนดส่งให้เองโดยข้อมูลเดิมไม่หาย งานจากไฟล์เก่าจะเตือนเฉพาะตรงเวลา จนกว่าจะตั้ง ⏰ เพิ่ม และก่อนบันทึกเป็นรูปแบบใหม่ครั้งแรก โปรแกรมจะสำรองไฟล์เดิมไว้ในโฟลเดอร์เดียวกัน โดยตั้งชื่อตามรุ่นของไฟล์ คือ `note.v2.bak` สำหรับไฟล์รุ่น 1.x/2.0, `note.v3.bak` สำหรับไฟล์รุ่น 2.1.0 และ `note.v4.bak` สำหรับไฟล์รุ่น 2.2–2.3 (รูปแบบรุ่น 4) โปรแกรมไม่ทับไฟล์สำรองที่มีอยู่แล้ว ถ้าชื่อซ้ำจะเติมวันเวลาต่อท้าย เช่น `note.v3.20261109141500.bak` ถ้ารุ่น 2.3.x เปิดไฟล์ของ 2.4.0 (v5) จะเปิดตารางได้ ไม่ปฏิเสธและไม่ลบฟิลด์ใหม่ แต่จะยังไม่แสดงตั้งค่าคอลัมน์และสีแถว

**เครื่องของฉันเปิดตารางโน้ตใช้เวลาเท่าไร**
บรรทัดแรกของ **ประวัติ** ในแถบการทำงานบอกจำนวนแถวที่เปิดและเวลาที่ใช้ตอนเปิด ส่วน `tablenote.log` (ข้าง `note.json`) มีรายละเอียดตั้งแต่รุ่น 2.6.1 เป็นบรรทัดเดียวต่อการเปิดหนึ่งครั้ง เช่น `start timeline (ms after the process started): code 90 ms · ui ready 300 ms · splash drawn 420 ms · table built 500 ms · editor shown 720 ms · editor opened 900 ms · editor ready 950 ms · editor drawn 960 ms` ถ้าเครื่องไหนเปิดช้า ส่งบรรทัดนี้มาด้วยจะรู้ว่าช้าที่ขั้นตอนไหน

**ค่าเตือนในไฟล์ผิด โปรแกรมจะลบตารางไหม**
ไม่ลบครับ ถ้าค่าใน `reminders` ผิดชนิด (เช่น `"offsets": ["15"]`) โปรแกรมจะทิ้งเฉพาะค่านั้น เก็บตารางที่เหลือไว้ครบ และจดไว้ในไฟล์ `tablenote.log` ข้าง `note.json`

**ขึ้นข้อความว่า "ไฟล์บันทึกอ่านไม่ได้" แล้วตารางว่างเปล่า ทำอย่างไร**
ข้อมูลเดิมยังอยู่ครับ โปรแกรมย้ายไฟล์เดิมไปเก็บเป็นสำเนา `.bak` ในโฟลเดอร์เดียวกัน

**ขึ้นข้อความว่า note.json ใหญ่เกิน 8 MB ทำอย่างไร**
ข้อมูลเดิมยังอยู่ครับ ถ้าโปรแกรมเปิดไฟล์ที่ใหญ่กว่า 8 MB (เพิ่มจาก 2 MB ในรุ่น 2.3.0) จะสำรองไฟล์เต็มเป็น `note.overlimit-<วันเวลา>.bak` ในโฟลเดอร์เดียวกันก่อน แล้วเปิดตารางเท่าที่รองรับ ถ้าการบันทึกจะทำให้ `note.json` ใหญ่เกิน 8 MB ไฟล์ที่บันทึกล่าสุดจะไม่ถูกเขียนทับ ตารางตอนนี้จะถูกสำรองไว้ที่ `note.overlimit-<วันเวลา>.bak` และมีข้อความบอก ให้ลบข้อความบางส่วนแล้วจึงบันทึกใหม่ได้

**ขึ้นว่าตารางเต็ม หรือไฟล์มีแถวเกินขีดจำกัด เกิดอะไรขึ้น**
- เมื่อตารางครบ 1,000 แถว จะเพิ่มแถวอีกไม่ได้ (รวมรอบถัดไปของงานทำซ้ำ) และมีข้อความแจ้ง ให้ลบหรือย้ายแถวเก่าออกเพื่อให้มีที่ว่าง
- ถ้าไฟล์มีแถวเกินขีดจำกัด โปรแกรมจะสำรองไฟล์เต็มเป็น `note.overlimit-<วันเวลา>.bak` ในโฟลเดอร์เดียวกันก่อน (เช่น `note.overlimit-20261109153000.bak` ซึ่งโปรแกรมจะไม่ลบเอง) แล้วเปิด 1,000 แถวแรกพร้อมข้อความแจ้ง

**กู้คืนจาก .bak ทำอย่างไร**
1. คลิกขวาไอคอนในถาดแล้วเลือก **ออก** เพื่อปิดโปรแกรมให้สนิท
2. เปิดโฟลเดอร์ `%APPDATA%\TableNote`
3. หาไฟล์ชื่อ `note.json.bak`, ไฟล์ชื่อแบบ `note.json.20261109153000.bak` ที่มีวันเวลาอยู่ในชื่อ, `note.v2.bak` (ข้อมูลจากรุ่น 1.x/2.0), `note.v3.bak` (ข้อมูลจากรุ่น 2.1.0) หรือ `note.v4.bak` (ข้อมูลจากรุ่น 2.2–2.3) แล้วเลือกไฟล์ที่ต้องการ
4. เปลี่ยนชื่อไฟล์ `note.json` ตัวปัจจุบันเป็นชื่ออื่นเก็บไว้ก่อน เช่น `note-new.json`
5. คัดลอกไฟล์ `.bak` ที่เลือก แล้วเปลี่ยนชื่อสำเนาเป็น `note.json`
6. เปิดโปรแกรมใหม่ ถ้ายังขึ้นว่าอ่านไม่ได้ แปลว่าไฟล์นั้นเสียจริง ให้ลองไฟล์ .bak ตัวอื่น

**ไฟล์สำรองเก็บไว้ตลอดไหม**
ไม่ใช่ทุกไฟล์ จากรุ่น 2.3.0 โปรแกรมเก็บ `note.json*.bak` ไว้แค่ 5 ไฟล์ล่าสุด (สำเนาที่ทำเมื่อไฟล์บันทึกอ่านไม่ได้หรือใหญ่เกินไป) เมื่อมีไฟล์ใหม่ ไฟล์เก่าที่สุดจะถูกลบ ถ้าต้องการเก็บไฟล์ใดไว้ ให้คัดลอกไปโฟลเดอร์อื่น

ไฟล์สำรองตามรุ่น (`note.v2.bak`, `note.v3.bak` เป็นต้น) และไฟล์สำรองเต็มเมื่อมีแถวเกินขีดจำกัด (`note.overlimit-<วันเวลา>.bak`) จะไม่ถูกลบเอง และไม่นับรวมใน 5 ไฟล์นี้

ถ้าไฟล์สำรองที่เติมวันเวลาจะได้ชื่อซ้ำ โปรแกรมจะเติม `-1`, `-2` ต่อท้ายชื่อไฟล์ใหม่ จึงไม่ทับไฟล์สำรองที่มีอยู่แล้ว

**ทำไมบันทึกไม่ได้**
แถบสถานะจะขึ้นว่า "บันทึกไม่สำเร็จ" พร้อมสาเหตุ เช่น ไฟล์ถูกโปรแกรมอื่นล็อกอยู่ ให้ลองปิดโปรแกรมที่อาจเปิดไฟล์นั้นค้างไว้ แล้วแก้ไขช่องใดช่องหนึ่งอีกครั้งเพื่อให้โปรแกรมบันทึกใหม่

**ลบผิดแล้วย้อนกลับได้ไหม**
ได้ครับ การลบแถว (F6) การลบคอลัมน์ (F8) และการลบข้อความในช่อง กด Ctrl+Z ย้อนได้ทั้งหมด (สูงสุด 100 ขั้น ประวัติย้อนจะหายเมื่อปิดโปรแกรม)

**ทำไมกด "ปิด" แล้วไม่เตือนอีก**
ปุ่ม **ปิด** และ **รับทราบ** แปลว่ารับทราบ จึงไม่เตือนซ้ำสำหรับเวลาเตือนนั้น ถ้าอยากให้เตือนอีก ให้แก้กำหนดส่งใหม่ คราวหน้าถ้ายังไม่พร้อมทำ ให้กด **X** หรือ **เลื่อน 10 นาที** แทน

**ทำไมพิมพ์สถานะว่า "ยังไม่เสร็จ" แล้วยังเตือนอยู่**
ถูกต้องครับ คำนี้ไม่นับว่าเสร็จ (จากรุ่น 2.3.0 เมื่อเปิดไฟล์ จะถูกแปลงเป็นสถานะยังไม่เสร็จ) ถ้าเสร็จแล้วให้เลือก `เสร็จแล้ว` จากรายการ

**ดูรุ่นของโปรแกรมได้ที่ไหน**
เลือกเมนู **ช่วยเหลือ → วิธีใช้** หรือคลิกขวาไอคอนในถาดแล้วเลือก **วิธีใช้** หรือ **Log** บรรทัดแรกจะบอกรุ่น เช่น ตารางโน้ต รุ่น 2.3.0

**ทำไมกดปิดหน้าต่างแล้วโปรแกรมยังอยู่**
ตั้งใจให้เป็นแบบนี้ เพื่อให้การเตือนทำงานต่อ โปรแกรมอยู่ที่ถาดไอคอน ถ้าจะออกจริงให้คลิกขวาไอคอนในถาดแล้วเลือก **ออก**

**เปลี่ยนภาษาหรือขนาดแล้วกลับเป็นภาษาอังกฤษ / 100% ทำไม**
ภาษาและขนาดเก็บใน `settings.json` ข้างไฟล์ `note.json` (บน Windows คือ `%APPDATA%\TableNote\settings.json`) ถ้าไฟล์นั้นเสียหรือหาย โปรแกรมจะกลับไปใช้ภาษาอังกฤษและขนาด 100% งานใน `note.json` ไม่ได้รับผลกระทบ เลือกภาษาและขนาดใหม่อีกครั้งได้เลย

**ส่งออกตารางเป็นไฟล์ txt หรือ Excel ได้ไหม**
ได้ครับ กด **ส่งออก** แล้วเลือก .txt, .csv หรือ .xlsx (ดูข้อ 13) หรือใช้ **คัดลอกพร้อมหัว** แล้ววางใน Excel ก็ได้

## 11. การเปลี่ยนภาษา

- หน้าต่างโปรแกรมเป็น**ภาษาอังกฤษ**เป็นค่าเริ่มต้นสำหรับทุกคน รวมคนที่อัปเกรดจากรุ่นเก่า เมื่อเลือกภาษาแล้ว โปรแกรมจะจำค่าไว้
- สลับภาษาได้ที่เมนู **มุมมอง → ภาษา** (View → Language) หรือ **Language / ภาษา** ในเมนูถาด แล้วเลือก **English** หรือ **ไทย**
- การเปลี่ยนมีผลทันที ไม่ต้องเปิดโปรแกรมใหม่ หน้าต่างเตือนที่เปิดค้างอยู่จะยังเป็นภาษาเดิมจนกว่าจะปิด
- ภาษาที่เลือกเก็บใน `settings.json` ข้างไฟล์ `note.json` ดังนั้นครั้งถัดไปโปรแกรมจะจำค่าไว้ การสลับภาษาไม่เปลี่ยน `note.json`
- การเปลี่ยนภาษาเปลี่ยนเฉพาะข้อความของหน้าต่างโปรแกรม ข้อมูลตาราง สถานะ และค่าทำซ้ำไม่เปลี่ยน เพราะสถานะและค่าทำซ้ำเก็บเป็นรหัส แล้วแปลเฉพาะป้าย (ดูข้อ 2) ข้อความที่พิมพ์เอง รวมหัวคอลัมน์ที่เปลี่ยนชื่อไว้ ยังคงตามที่พิมพ์
- ถ้า `settings.json` เสียหรือหาย โปรแกรมจะกลับไปใช้ภาษาอังกฤษ
- ทั้งสองภาษาแสดงและบันทึกปีเป็นปฏิทินตะวันตก (ค.ศ. เช่น 2026) ยังพิมพ์ปี พ.ศ. ในคอลัมน์กำหนดส่งได้: ปีตั้งแต่ 2400 ขึ้นไปถือเป็น พ.ศ. และจะลบ 543 (เช่น 2569 กลายเป็น 2026) ใช้ได้ทั้งสองภาษา

## 12. การขยายและย่อหน้าจอ (ซูม)

- ใช้ปุ่ม **A−**, **100%** และ **A+** บนแถบเครื่องมือ เมนู **มุมมอง** หรือเมนูถาด
- หรือกด **Ctrl++** เพื่อขยาย, **Ctrl+−** เพื่อย่อ และ **Ctrl+0** เพื่อกลับ 100% กด **Ctrl** ค้างแล้วหมุนล้อเมาส์ก็ได้
- ขนาดมีได้ตั้งแต่ 80% ถึง 200% ทีละ 10% แถบสถานะจะแสดงขนาดปัจจุบันทุกครั้งที่เปลี่ยน
- ขยาย/ย่อเฉพาะกล่องแจ้งเตือนกับตาราง เมนู แถบเครื่องมือ และแถบสถานะขนาดเท่าเดิม (ตั้งแต่ 2.6.0) ตารางบนวอลเปเปอร์ก็ใช้ขนาดเดียวกัน
- ระดับการขยายเก็บใน `settings.json` ข้างไฟล์ `note.json` ดังนั้นครั้งถัดไปโปรแกรมจะจำค่าไว้ ถ้า `settings.json` เสียหรือหาย ขนาดจะกลับเป็น 100%

## 13. การส่งออกตาราง

กด **ส่งออก** บนแถบเครื่องมือ แล้วเลือกชนิดไฟล์:

| ชนิดไฟล์ | ได้อะไร |
|---|---|
| **ข้อความ (.txt)** | ข้อความล้วน คั่นคอลัมน์ด้วยแท็บ แท็บและการขึ้นบรรทัดในช่องจะกลายเป็นช่องว่าง |
| **CSV (.csv)** | ค่าคั่นด้วยจุลภาค ใช้กับ Excel, Google Sheets และโปรแกรมอื่นได้ |
| **Excel (.xlsx)** | ไฟล์ Excel ที่เปิดใน Excel ได้โดยตรง |

- ทั้งสามชนิดรองรับข้อความภาษาไทย
- **.xlsx**: ช่องจะถูกบันทึกเป็นตัวเลขเฉพาะเมื่อ Excel จะแสดงกลับมาตรงกับที่พิมพ์ทีละตัวอักษร เช่น `12`, `-5` หรือ `3.25` ค่าอย่าง `+3.5`, `12.50`, `-0`, `007`, `1e5` และตัวเลขที่ยาวเกิน 11 หลักก่อนจุดทศนิยม เช่น เลขบัตรประชาชน 13 หลัก (Excel จะแสดงเป็น `1.10370E+12`) จะถูกบันทึกเป็นข้อความ จึงไม่ถูกเปลี่ยน ช่องอื่นทั้งหมดบันทึกเป็นข้อความ ไม่มีสูตร
- **.csv และ .txt**: ช่องที่ขึ้นต้นด้วย `=`, `+`, `-`, `@`, แท็บ หรือการขึ้นบรรทัด จะมี `'` นำหน้า เพื่อไม่ให้ Excel ถือว่าเป็นสูตร ตัวเลขล้วนอย่าง `-5` หรือ `+3.5` คงเป็นตัวเลข
- ป้ายสถานะและค่าทำซ้ำในไฟล์ที่ส่งออกเป็นไปตามภาษาที่เลือกอยู่ เช่น `Done` และ `Weekly` ในภาษาอังกฤษ หรือ `เสร็จแล้ว` และ `ทุกสัปดาห์` ในภาษาไทย สถานะที่พิมพ์เองจะส่งออกตามที่พิมพ์
- สถานะว่างจะถูกส่งออกเป็น `ยังไม่เริ่ม` ในภาษาไทย หรือ `Not started` ในภาษาอังกฤษ เหมือนที่เห็นบนหน้าจอ
- เมื่อติ๊ก **ซ่อนงานเสร็จ** อยู่ จะส่งออกเฉพาะแถวที่เห็น ถ้าต้องการส่งออกงานที่เสร็จแล้วด้วย ให้ติ๊ก **รวมงานที่เสร็จแล้ว** ในหน้าต่างส่งออก
- กำหนดส่งถูกเขียนเป็นข้อความรูปแบบ `yyyy-MM-dd` หรือ `yyyy-MM-dd HH:mm` เมื่องานมีเวลา โดยใช้ปี ค.ศ.
- แถวแรกของไฟล์เป็นหัวคอลัมน์ ตามด้วยแถวข้อมูลตามลำดับที่เห็นบนหน้าจอ
- ชื่อไฟล์ที่แนะนำคือ `TableNote-YYYY-MM-DD` ผู้ใช้เลือกโฟลเดอร์ในกล่องโต้ตอบบันทึก ชนิดไฟล์เริ่มต้นในกล่องโต้ตอบคือ Excel (.xlsx) **ส่งออก…** ในเมนูถาดจะเปิดหน้าแก้ไขก่อน (ถ้าอยู่ในโหมดวอลเปเปอร์ วอลเปเปอร์เดิมจะกลับมา)


## 14. ย้ายคอลัมน์และแถว ตั้งค่าคอลัมน์ และสีแถว

**คอลัมน์**
- ลากที่จับ **⋮⋮** ด้านซ้ายของหัวคอลัมน์เพื่อย้ายคอลัมน์ หรือคลิกขวาที่หัวคอลัมน์แล้วเลือก ย้ายไปทางซ้าย / ขวา / ซ้ายสุด / ขวาสุด หรือกด **Alt+Shift+←** / **Alt+Shift+→**
- คลิกขวาที่หัวคอลัมน์แล้วเลือก **ลบคอลัมน์นี้…** เพื่อลบ โปรแกรมจะถามยืนยันทุกครั้ง คอลัมน์กำหนดส่งลบไม่ได้
- คลิกขวาที่หัวคอลัมน์แล้วเลือก **ตั้งค่าคอลัมน์…** เพื่อตั้งชื่อ ความกว้าง และชนิด:
  - **ข้อความ** (ค่าเริ่มต้น), **ตัวเลข**, **ตัวเลือก** (รายการแบบดรอปดาวน์ พิมพ์บรรทัดละหนึ่งรายการ), **ช่องทำเครื่องหมาย** (✓) หรือ **นับวัน**
  - การเปลี่ยนชนิดไม่แก้ข้อความที่มีอยู่ในช่อง (คอลัมน์ว่างที่เปลี่ยนเป็นนับวัน จะเริ่มนับจากวันนี้ในแถวที่ยังไม่เสร็จ)
  - คอลัมน์สถานะและกำหนดส่งตั้งได้แค่ชื่อกับความกว้าง

**นับวัน (2.6.0)**
- เมนู **ตาราง → เพิ่มคอลัมน์นับวัน** เพิ่มคอลัมน์ "นับวัน" ไว้ก่อนคอลัมน์สถานะ แต่ละช่องเก็บวันรับงาน และแสดงว่าผ่านมากี่วันแล้ว: "วันนี้", "1 วัน", "150 วัน" งานที่ยังไม่เสร็จเริ่มนับจากวันนี้ แถวที่เพิ่มทีหลังเริ่มนับตั้งแต่วันที่เพิ่ม
- ตั้งสถานะเป็น **เสร็จแล้ว** จะหยุดนับ และแสดงว่าใช้เวลากี่วัน เช่น "42 วัน ✓"
- คลิกช่องนับวัน (หรือกด **Space**) เพื่อเปิดหน้าต่างรายละเอียด จะเห็นว่าค้างมากี่วัน ตั้งแต่วันไหนถึงวันไหน **วันรับงาน** (เลือกวันอื่น หรือกด **วันนี้**) สถานะและตั้งแต่เมื่อไร และอัปเดตล่าสุด
- ด้านล่างเป็นประวัติของแถวจากใหม่ไปเก่า: เปลี่ยนสถานะ แก้ข้อมูลในแถว และบันทึกความคืบหน้า แต่ละรายการมีวันที่ เวลา และนับเป็นวันที่เท่าไรหลังรับงาน ("หลังรับงาน 141 วัน") พิมพ์บันทึก เช่น "โทรตามแล้ว ลูกค้าจะส่งเอกสารวันศุกร์" แล้วกด **Enter** (หรือ **เพิ่มบันทึก**) จะแก้บันทึกให้กด **แก้ไข** ข้างบันทึกนั้น (หรือดับเบิลคลิกที่บันทึก) แก้ข้อความแล้วกด **Enter** หรือ **บันทึก** ถ้าเปลี่ยนใจกด **Esc** หรือ **ยกเลิก** ข้อความเดิมจะกลับมา บันทึกยังอยู่ที่วันเวลาเดิม และมีบรรทัดบอกว่าแก้ไขเมื่อไร ("แก้ไขเมื่อ 21/11/2026 08:05") ถ้ากำลังแก้บันทึกหนึ่งอยู่แล้วไปแก้บันทึกอื่น เพิ่มบันทึก หรือปิดหน้าต่าง ข้อความที่แก้จะถูกเก็บไว้ จะลบบันทึกให้กด **✕** แล้วกด **ลบ?**
- ประวัติเริ่มเก็บตั้งแต่ตารางมีคอลัมน์นับวัน แก้ช่องเดิมภายใน 10 นาทีนับเป็นรายการเดียว และการพิมพ์ข้อมูลแรกของแถวใหม่ไม่ขึ้นในประวัติ (เปลี่ยนสถานะขึ้น) Ctrl+Z การแก้ไขจะขึ้นเป็นการเปลี่ยนแปลงอีกรายการ บันทึกความคืบหน้าไม่อยู่ใน Ctrl+Z
- ส่งออกและคัดลอกได้เป็นวันรับงาน (`yyyy-MM-dd`) ส่วนส่งออกภาพ พิมพ์ และวอลเปเปอร์แสดงเป็นจำนวนวัน

**แถว**
- ลาก **เลขแถว** เพื่อย้ายแถว หรือคลิกขวาแล้วเลือก เลื่อนขึ้น / ลง / ไปบนสุด / ไปล่างสุด หรือกด **Alt+Shift+↑** / **Alt+Shift+↓** เมื่อติ๊ก **ซ่อนงานเสร็จ** การย้ายจะข้ามแถวที่ซ่อน
- คลิกขวาที่เลขแถวเพื่อตั้งสี (8 สี หรือไม่มีสี) เปิด/ปิด **ไฮไลต์** หรือ **ล้างค่า** สีตามแถวไปเมื่อย้ายหรือเรียง และบันทึกทันที

การย้ายคอลัมน์หรือแถว การลบคอลัมน์ การตั้งค่าคอลัมน์ และการเปลี่ยนสีหรือไฮไลต์แถว ย้อนกลับได้ทั้งหมดด้วย **Ctrl+Z**

## 15. กล่องแจ้งเตือน

เลือกเมนู **ตาราง → เพิ่มกล่องแจ้งเตือน** เพื่อเพิ่มกล่อง ช่องกล่องแจ้งเตือนเหนือตารางจะซ่อนไว้เมื่อยังไม่มีกล่อง และขึ้นมาพร้อมกล่องแรก ปุ่ม **+ กล่องแจ้งเตือน** ในช่องนั้นเพิ่มกล่องต่อไป แต่ละกล่องมีหัวข้อและข้อความที่แก้ได้ กด **ลบ** แล้วโปรแกรมจะถามยืนยันก่อนเอาออก การลบนี้กู้คืนไม่ได้ ลากที่จับ **⋮⋮** เพื่อเรียงลำดับ หรือใช้ปุ่ม **ขึ้น** และ **ลง** ซึ่งใช้ได้โดยไม่ต้องลาก และเข้าถึงด้วยคีย์บอร์ดได้ กล่องและลำดับถูกบันทึกใน `note.json` และยังอยู่หลังปิดแล้วเปิดใหม่ คนละอย่างกับการเตือนตามกำหนดส่ง Ctrl+Z ไม่ย้อนการแก้กล่องแจ้งเตือน

## 16. ส่งออกเป็นภาพและสั่งพิมพ์

**ส่งออกเป็นภาพ**
1. เลือกเมนู **ไฟล์ → ส่งออกภาพ**
2. เลือก **PNG (.png)** หรือ **JPEG (.jpg)** แล้วเลือกโฟลเดอร์ ชื่อไฟล์ที่แนะนำคือ `TableNote-YYYY-MM-DD`

**สั่งพิมพ์** (สั่งพิมพ์ได้เฉพาะบน Windows)
1. เลือกเมนู **ไฟล์ → พิมพ์** จะเปิดหน้าต่าง **ตัวอย่างก่อนพิมพ์** ขึ้นมา
2. กด **พิมพ์** เพื่อส่งไปที่เครื่องพิมพ์ หรือกด **ปิด** เพื่อยกเลิก

**สิ่งที่ควรรู้**
- ภาพและงานพิมพ์มีแค่ตาราง ไม่มีแถบเครื่องมือ ช่องที่เลือก หรือปุ่มต่างๆ ติดมา
- สีหัวคอลัมน์ สีช่องเลขแถว สีสถานะ สีแถว และสีที่ตั้งรายช่องยังอยู่ครบ โดยสีช่องจะแสดงแทนสีแถว และสีแถวจะแสดงแทนสีสถานะ เหมือนบนจอ
- ไอคอน ⚠ และ ⏰ ออกมาเหมือนบนจอ วันที่แสดงแบบ `dd/MM/yyyy` เหมือนบนจอ
- ส่งออกเฉพาะแถวที่เห็นอยู่ ถ้าติ๊ก **ซ่อนงานเสร็จ** ไว้ งานที่เสร็จแล้วจะไม่ออกมา คอลัมน์ที่ยุบไว้ก็จะไม่ออก (แต่ .csv และ .xlsx ยังได้ครบทุกคอลัมน์)
- ตารางที่กว้างเกินหน้ากระดาษจะถูกย่อให้พอดีความกว้างหน้า ส่วนที่ยาวลงไปจะขึ้นหน้าใหม่ตรงขอบแถว และหัวคอลัมน์จะซ้ำทุกหน้า
- ถ้ามีหลายหน้า ระบบจะรวมเป็นไฟล์เดียวแล้วสั่งพิมพ์รอบเดียว
- ตัวหนังสือในหน้าตัวอย่างก่อนพิมพ์อาจดูเบลอกว่างานพิมพ์จริงเล็กน้อย งานที่พิมพ์ออกมาจะคมกว่า
- การซูมหน้าจอไม่มีผลกับภาพ ใช้ได้ตอนแก้ไขตาราง และไม่แก้ `note.json`

**ข้อจำกัดในเวอร์ชันนี้**
- รองรับเฉพาะกระดาษ A4 ส่วนขอบกระดาษ และการเลือกพิมพ์สีหรือขาวดำ ต้องตั้งในหน้าต่างพิมพ์ของ Windows
- ถ้าเครื่องไม่มีโปรแกรมที่สั่งพิมพ์ PDF ผ่านระบบได้ (เช่น ใช้ Edge เปิด PDF) ระบบจะพิมพ์ทีละหน้าแทน และหน้าต่างพิมพ์อาจเปิดขึ้นมาทีละหน้า
- ถ้ามีแถวไหนสูงเกินหนึ่งหน้า แถวนั้นจะต่อไปหน้าถัดไป และอาจถูกตัดกลางบรรทัด
- ไฟล์ที่ใช้พิมพ์จะค้างอยู่ใน `%TEMP%\TableNote-print` จนกว่าจะเปิดแอปใหม่หรือสั่งพิมพ์ครั้งถัดไป
- งานพิมพ์เป็นภาพ ถ้าพิมพ์ออกเป็น PDF จะคัดลอกหรือค้นหาข้อความไม่ได้
- ตารางที่กว้างมากจะถูกย่อจนตัวหนังสือเล็กมาก
- ภาพที่ส่งออกมีความละเอียดเท่าบนจอ ถ้าต้องการงานพิมพ์ที่คม ให้กด **พิมพ์** ในแอป
- สีตัวเลขในช่องเลขแถวและสีพื้นทั้งตารางยังไม่ออกในภาพและงานพิมพ์

## 17. วาดเขียนบนตาราง เลเยอร์ และรูปภาพ

คลิก **วาดเขียน** บนแถบเครื่องมือ (หรือ **ตาราง → วาดเขียนบนตาราง**) จะมีแถบเครื่องมือวาดขึ้นใต้แถบเครื่องมือ แล้วเขียนหรือวาดลงบนตารางได้เลยด้วยเมาส์ ปากกาสไตลัส หรือนิ้ว คลิก **เสร็จ** หรือกด **Esc** เพื่อกลับไปแก้ไขตาราง สิ่งที่วาดไว้ยังอยู่บนตาราง

| เครื่องมือ | ปุ่มลัด | ทำอะไร |
|---|---|---|
| **ปากกา** | P | เขียนหรือวาดอิสระ |
| **ยางลบ** | E | ลบเส้นในเลเยอร์ที่เลือกเมื่อลากผ่าน ปลายยางลบของปากกาสไตลัสก็ลบได้ |
| **ไม้บรรทัด** | R | ลากจากจุดเริ่มถึงจุดปลายเพื่อได้เส้นตรง กด **Shift** ค้างไว้เพื่อล็อกมุมทีละ 15° |
| **ย้าย** | M | ลากรูปภาพเพื่อย้าย ลากมุมขวาล่างเพื่อย่อ/ขยาย (Shift ไม่คงสัดส่วน) กด **Delete** เพื่อลบ |

- **สี:** คลิกเลือกสี หรือพิมพ์ `#RRGGBB` แล้วกด Enter **ขนาด:** 1–60 (ยางลบมีขนาดแยก)
- **ความคมชัด 0–100%:** ความชัดของเลเยอร์ที่เลือก 100% = ชัดเต็มที่ 50% = จางลงครึ่งหนึ่ง ค่าน้อยลงอีก = จางลงอีก ใช้กับทั้งเลเยอร์ (เส้นและรูปภาพ) ทันที แต่ละเลเยอร์ตั้งค่าแยกกัน และชื่อเลเยอร์จะแสดง % เมื่อต่ำกว่า 100%
- **ลบทั้งหมด** ถามก่อนแล้วล้างเลเยอร์ที่เลือก **↩ / ↪** หรือ **Ctrl+Z / Ctrl+Y** ย้อนกลับและทำซ้ำภาพวาดระหว่างอยู่ในโหมดวาด
- ล้อเมาส์ยังเลื่อนตารางได้ ภาพวาดเลื่อนตาม และอยู่ตรงตำแหน่งที่วาดบนตาราง การย้าย เรียง หรือซ่อนแถวจะไม่ย้ายภาพวาด

**เลเยอร์** แถบเครื่องมือแสดงรายชื่อเลเยอร์ ติ๊กหรือเอาติ๊กออกเพื่อเปิด/ปิดเลเยอร์ คลิกชื่อเพื่อวาดบนเลเยอร์นั้น **+ เลเยอร์** เพิ่มเลเยอร์ (สูงสุด 10) **เปลี่ยนชื่อ** และ **ลบเลเยอร์** ใช้กับเลเยอร์ที่เลือก เมื่อไม่ได้อยู่ในโหมดวาด เปิด/ปิดเลเยอร์ได้ที่ **มุมมอง → เลเยอร์โน้ต**

**รูปภาพบนเลเยอร์** **+ รูปภาพ** วางภาพ PNG, JPEG, BMP, GIF หรือ WebP บนเลเยอร์ที่เลือก แล้วใช้ **ย้าย** จัดตำแหน่งและขนาด

**ภาพในช่อง** คลิกขวาที่ช่องแล้วเลือก **ใส่ภาพในช่อง…** (หรือ **ตาราง → ภาพในช่องที่เลือก…**) ช่องนั้นจะมีปุ่ม **ภาพ ▾** และแสดงภาพใต้ข้อความ คลิกปุ่ม (**ภาพ ▸**) เพื่อปิดภาพ คลิกอีกครั้งเพื่อเปิด คลิกที่ภาพเพื่อดูเต็ม คลิกขวาที่ช่องเพื่อ **เปลี่ยนภาพ…** **แสดง / ซ่อนภาพ** และ **เอาภาพออก…**

ทุกอย่างบันทึกอัตโนมัติใน `layers.json` ข้าง `note.json` และคัดลอกรูปภาพไว้ในโฟลเดอร์ `images` ข้าง ๆ เลเยอร์และภาพในช่องยังไม่อยู่ในภาพที่ส่งออก การพิมพ์ และวอลเปเปอร์
