# Changelog

All notable changes to TableNote. [ภาษาไทย](CHANGELOG.th.md)

- **2.5.1** (19 November 2026)
  - Fixed: a due date with a month name or a two-digit year (`5 Jan 2026`, `January 5, 2026`, `5 ม.ค. 2026`, `5-Jan-26`, `5/1/26`), for example pasted from Excel, was read as 1483 or 1983: the task showed as overdue at once, a "missed" reminder popped up, and a monthly repeat created its next task in 1683. It happened on English Windows too. Buddhist Era input converts as before.
  - Fixed: with **Hide done** on, pasting several lines wrote into the hidden done rows, so a pasted line disappeared and that task's text was overwritten. Pasted lines now go into the visible rows only.
  - Fixed: undoing a row delete (Ctrl+Z) brought the row back without its detail tables and detail buttons, which were then lost for good.
  - Fixed: undoing a column delete brought the column back without its header and cell colours. Undoing a delete of the reminder date column made every acknowledged overdue task pop up again and lost snoozes and reminder-card colours.
  - Fixed: if another program was using `note.json` at start-up (antivirus, a backup tool), TableNote ran the whole session on an empty stand-in table, so nothing reminded (started at sign-in, it sat in the tray all day), and the stand-in's default "launch at sign-in: off" deleted the sign-in entry, so TableNote didn't start at the next sign-in either. Now the sign-in setting is left alone, and TableNote keeps trying and opens `note.json` as soon as it can be read. If something was typed into the stand-in table, it is kept in `note.unsaved.json` and TableNote asks for a restart instead. The next start renames that file to `note.unsaved-<time>.json`, so a later session can't overwrite it, and says so. A new alert box or colour in such a session is now saved too.
  - Fixed: when the tray icon couldn't be created, closing the window left TableNote running invisibly (starting it again did nothing until it was ended in Task Manager). Closing the window now exits, as the README says.
  - Fixed: the Help window showed version 2.4.2, and the in-app change log had no 2.5.0 entry.
  - Changed: the silent Windows toast is removed; the reminder window and its sound are unchanged. The Windows exe is trimmed: about 24 MB instead of 56 MB, and it uses less memory. `note.json` is written exactly as before.
- **2.5.0**
  - Format version is 6. A 2.4.2 file (version 5, no new fields) still opens; the first save writes version 6 and keeps the table.
  - Collapsible column groups, a detail table on chosen cells, user alert boxes, an RGB colour picker (`partColors`, alert boxes as `alert:{id}`), typed column width (72–800) and row height (`rowHeights`), and image export / print of the visible table.
  - CSV, XLSX, and Excel copy include collapsed columns. Image export and print skip them (`ColumnGroupOps.IsHidden`) and use the saved row height.
  - Image and print take cell background and text (`cell:{rowId}:{columnId}`), header background and text (`header:{columnId}`, falling back to `section:header`), and the row-number background (`rownum:{rowId}`). They do not draw `alert:` colours, row-number text colour, or `section:table`.
  - Toolbar buttons are grouped into 5 labelled groups. A top menu bar (File / Table / Column / Row / View / Help) reuses the right-click menu builders.
  - The status column and the reminder-date column can be deleted and added back, at most one of each. Files saved before that still open.
  - Print fixes: a page break does not split a row, the column header is repeated on every page, a multi-page job is sent as one PDF, print pages are 200 dpi, and temporary print files are kept and removed after one hour.
  - New: user-managed alert boxes above the table. Add a box, edit its title and text, delete it (the delete dialog asks first; this can't be undone), drag the ⋮⋮ grip to reorder, or use Up / Down without dragging. Content and order are saved in `note.json` (optional `alertBoxes`, format version stays 5, stable `id` per box). A missing or corrupt `alertBoxes` value is skipped and the table still opens. Unknown fields on a box are kept so a later per-box colour can use the same id. Alert-box edits are not part of Ctrl+Z.
  - New: **Colors** on the toolbar opens an RGB / hex picker for the selected cell (background and text), the row number, column headers, and the main sections (window, toolbar, status bar, notice banner, table). The reminder window and each reminder card can be colored too. Choices are saved in `note.json` under optional `partColors` (the format version stays 5; a file without the field uses the built-in colors) and restored on startup. Reset clears a part back to its built-in color.
  - An alert box is colored by its stable id in `partColors` as `alert:{id}` only. That still works when `alertBoxes` is a known list. A file with no `alertBoxes` still opens.

Known limitations
  - Pasting headers across collapsed groups is unsupported. There is no collapse/expand-all menu. A child column cannot be dragged out of its group. Excel (.xlsx) export does not use custom column widths. Multi-column selection is shift-click only. Edge-drag resize still uses the old method. Reset width sets 140 even for Status and Due.
  - Not tested here: an 800px column, an empty table, and cancelling the print dialog on Windows.
  - Printing has not been tested on a real Windows printer. If the PDF print verb fails, printing falls back to one PNG per page, which may show one dialog per page.
  - Deleting the status column makes rows that were done but overdue alert again, because nothing marks them done.
  - Undo does not restore `notify:*` colours.
  - Toolbar group labels are a fixed 124px wide, so a long Thai label wraps.
  - The “+ column” flyout itself does not check view mode. The hidden button and `AddSystemColumnAsync` guard it.
  - Deleting an alert box leaves its `alert:{id}` colour in `partColors` (harmless; it is not drawn).
  - Text (.txt) export includes the "(details)" column.
  - Image and print do not draw row-number text colour or `section:table`.
  - NotifyTests `CrashLog: unobserved task exception logged` is a pre-existing flake on main, not caused by this integration.
  - The width field in the older Column settings dialog (`ColumnSettingsDialog`) still uses a numeric stepper. It silently clamps and rounds (801 becomes 800). The new 2.6 column-width dialog rejects a number outside 72–800. These two will be unified next round.
- **2.4.2** (12 November 2026)
  - New: English is the primary language. All UI text lives in `lang/en.json` and `lang/th.json`; add a language by adding a JSON file (see CONTRIBUTING.md). Export labels, dates (`yyyy-MM-dd`, `yyyy-MM-dd HH:mm`), and the log are language-independent or English.
  - New: taskbar icon while editing, tray icon only when attached to the desktop background; the mode is kept after restart.
  - Fixed: TableNote could close without warning when several reminders came due at once; reminder popup, toast and sound are now guarded, and any unexpected error is written to `tablenote.log` instead of closing the app.
  - Repo: MIT LICENSE, font OFL, CHANGELOG, CONTRIBUTING; build output no longer tracked.
- **2.4.1** (12 November 2026)
  - Fixed: reading a `note.json` saved as Thai ANSI (Windows-874), locked `note.json` handling, upgrade backups, column-id mismatch, long numbers in xlsx, pasted quotes, English UI wording, undo/redo save, help text.
- **2.4.0** (11 November 2026)
  - New: move columns by dragging the ⋮⋮ header grip, from the header menu, or with Alt+Shift+←/→; delete a column from the header menu (always confirms, undo with Ctrl+Z). Move rows by dragging the row number, from the row-number menu, or with Alt+Shift+↑/↓ (skips hidden rows when Hide done is on; undo with Ctrl+Z). Column settings (name, width, type: text / number / choice / check) from the header menu. Row colour (8 colours plus none) and highlight from the row-number menu; styles follow the row on move or sort and are saved immediately.
  - Compatibility: `note.json` version 5 adds `columnIds`, `columnSettings`, and `rowStyles`. Older files (v2–v4) open as usual and are backed up as `note.vN.bak` on the first save. Newer-version files are not downgraded; unknown fields are kept. A 2.3.x build opens a v5 file without rejecting it or dropping the new fields, but does not use those features.

- **2.3.0** (9 November 2026, includes 2.2.2)
  - Fixed: the main window and reminder popup could go "Not Responding" on Windows 10 (desktop-attach Win32 calls to Explorer ran on the UI thread; now off-thread with SMTO_ABORTIFHUNG 1000 ms, a UI watchdog logs stalls > 2 s to `tablenote.log`); every reminder opened another popup (now one popup that gathers all reminders); the table built every cell of every row (now virtualized, 1000 rows usable); Ctrl+Home / Ctrl+End.
  - New: English/Thai (English default, choice saved in `settings.json`), zoom 80–200% (A− / 100% / A+, Ctrl +/−/0, Ctrl+wheel), Export to .xlsx / .csv / .txt, 1000 rows (bigger files are copied to `note.overlimit-<time>.bak` first), note.json cap 8 MB (not saved over when exceeded), log capped at 512 KB (2 files), 5 rolling `note.json*.bak`.
  - Storage: status saved as `todo`/`doing`/`done`, repeat as `none`/`daily`/`weekly`/`monthly:N`. Dates are CE; Buddhist-era years typed (≥ 2400) are converted.

- **2.2.2** (9 November 2026)
  - Fixed:
    - a popup left open for more than 2 minutes wrongly said "พลาดการเตือนเมื่อ …" (missed at …); lateness is now decided once, when the reminder appears;
    - a wrongly typed field outside `reminders` (for example `"version": "3"`, `"columnWidths": ["120"]`, `"hideDone": "true"`, a bad `window` or `rowIds`) made TableNote discard the whole table; each field now falls back to its default, and a notice points to `tablenote.log`;
    - a file from a newer TableNote (version 5 or higher) was saved over as version 4, losing unknown fields; it is now backed up as `note.v5.bak` first, keeps its version, and unknown fields are preserved;
    - `5/1/2026 9:00` could be misread on a Thai/Buddhist-calendar PC; it now always means 5 January 2026;
    - desktop (background) mode on Windows 10 is more robust: standard WorkerW/Progman attach, retries at startup, re-attach after Explorer restarts, a Win+D-proof fallback, and the failing step is logged.
  - Changed: when an open advance popup reaches the due time, the silent toast is shown too.
- **2.2.1** (9 November 2026)
  - Fixed:
    - saving the ⏰ dialog, even unchanged, made an acknowledged overdue task pop up again;
    - a wrongly typed value in `reminders` made TableNote treat the whole file as corrupt (move it to `.bak`); bad values are now dropped per task and logged;
    - a late advance reminder showed the configured offset instead of the real time left, and an advance popup left open past the due time didn't update;
    - the upgrade backup was skipped when `note.v2.bak` already existed; backups are now named by the old file's version and never overwritten.
  - Changed: the Windows toast is silent so the reminder sound plays only once.
- **2.2.0** (9 November 2026)
  - Added:
    - advance reminders (⏰) with presets or a custom time, up to 5 per task;
    - a per-task Acknowledge button in the popup;
    - closing the window now hides to the tray, and launch at sign-in starts hidden;
    - Windows toast through the Windows target framework;
    - undo for typing, header edits, paste, and F5/F7/F8, keyed by row id.
  - Fixed:
    - `ยังไม่เสร็จ` was counted as done;
    - Ctrl+Z didn't work while typing;
    - the monthly anchor on the 31st was lost;
    - date-only recurrences gained a 00:00 time;
    - the due column could be deleted.
- **2.1.0** (9 November 2026): calendar and time picker; daily, weekly, and monthly recurring tasks; combined reminder popup; Close counts as acknowledged and X snoozes; Buddhist Era years; columns tracked by role so headers can be renamed; strikethrough for done tasks; undo and redo for some actions; mute option.
- **2.0.0**: full rewrite of 1.0.0 with the reminder system, status dropdown, and row colors.
- **1.0.0**: first release.
