# ตารางโน้ต (TableNote)

โปรแกรมจดงานแบบตารางคล้าย Excel ขนาดเบา เตือนเมื่องานถึงกำหนดส่งและเตือนล่วงหน้าได้ สร้างด้วย Avalonia บน .NET 10

รุ่นล่าสุด: **2.7.0** (24 พฤศจิกายน 2026) หน้าต่างโปรแกรมเป็นภาษาอังกฤษเป็นค่าเริ่มต้น สลับเป็นไทยได้ที่เมนู **View → Language** (มุมมอง → ภาษา) คู่มือภาษาอังกฤษอยู่ที่ [`docs/manual-en.md`](docs/manual-en.md)

## TableNote คืออะไร

TableNote เป็นตารางโน้ตเล็กๆ ที่วางไว้บนหน้าจอ ใช้จดงานและตั้งกำหนดส่ง เมื่อถึงเวลาหรือก่อนถึงเวลาตามที่ตั้งไว้ โปรแกรมจะเด้งหน้าต่างเตือนพร้อมเสียง มีปฏิทินที่แสดงแถวเดียวกันตามวัน และกรอกงานของแต่ละวันในตารางป๊อปอัพได้ ใช้ได้ทั้งแบบหน้าต่างลอยอยู่บนสุด และแบบตั้งตาราง (และปฏิทินที่มุมขวาล่าง) เป็นวอลเปเปอร์ของ Windows ข้อมูลบันทึกอัตโนมัติลงไฟล์ JSON ในเครื่อง ไม่ต้องใช้อินเทอร์เน็ต

## ความสามารถหลัก

- **ปฏิทิน (2.7.0):** ปุ่ม **ปฏิทิน** บนแถบเครื่องมือ (F9, **ตาราง → ปฏิทิน…** หรือเมนูที่ถาด) แสดงทั้งเดือน ทุกแถวที่มีกำหนดส่งอยู่ในวันของมัน พร้อมเวลาและหัวข้อ สีเหมือนในตาราง ชี้ที่วันเพื่อดูรายละเอียด คลิกวันเพื่อเปิดตารางของวันนั้นเป็นป๊อปอัพ: คือแถวของตารางหลักที่กำหนดส่งวันนั้น กด **+ แถว** เพื่อเพิ่ม พิมพ์ที่นั่นแล้วตารางหลักเปลี่ยนทันที และแก้ในตารางหลักก็เปลี่ยนในปฏิทิน การแจ้งเตือนทำงานเหมือนทุกแถว และวางปฏิทินไว้บนวอลเปเปอร์มุมขวาล่างได้ ดู [ปฏิทิน](#ปฏิทิน)
- **วาดเขียนบนตารางเป็นเลเยอร์ (2.6.1.1):** ปุ่ม **วาดเขียน** บนแถบเครื่องมือเปิดโหมดวาด: ปากกา ยางลบ ไม้บรรทัด (กด Shift ล็อกมุมทีละ 15°) ลบทั้งหมด สีปากกา ขนาด ความคมชัด 0–100% ของแต่ละเลเยอร์ (ชัดถึงจาง) ย้อนกลับ / ทำซ้ำ และรูปภาพที่ย้ายและย่อ/ขยายได้ สูงสุด 10 เลเยอร์ เปิด/ปิดแต่ละเลเยอร์ด้วยช่องติ๊ก (หรือ **มุมมอง → เลเยอร์โน้ต**) **ภาพในช่อง:** คลิกขวาที่ช่อง → **ใส่ภาพในช่อง…** แล้วกดปุ่ม **ภาพ ▾ / ▸** ในช่องเพื่อเปิด/ปิดภาพ เก็บใน `layers.json` และ `images/` ข้าง `note.json`
- **เปิดเร็วขึ้น (2.6.1):** ไฟล์ exe เก็บโค้ดที่แปลงเป็นภาษาเครื่องไว้ล่วงหน้า โปรแกรมจึงเปิดเร็วขึ้นราว 3–4 เท่า และหลังเปิดใช้ CPU กับหน่วยความจำน้อยลง ช่องในตารางเบาลง `tablenote.log` บันทึกว่าแต่ละขั้นตอนตอนเปิดใช้เวลาเท่าไร ดู [docs/performance.md](docs/performance.md)
- **โหมดวอลเปเปอร์ (2.6.0, Windows):** ปุ่ม **วอลเปเปอร์** บนแถบเครื่องมือวาดตารางทับวอลเปเปอร์เดิมของคุณแบบเต็มจอ ตรงตำแหน่งที่หน้าต่างอยู่ แล้วหน้าแก้ไขไปอยู่ที่ถาด คลิกไอคอนที่ถาดหรือกด Ctrl+Shift+E เพื่อกลับมาแก้ไข แล้ววอลเปเปอร์เดิมจะกลับมา ดู [โหมดวอลเปเปอร์](#โหมดวอลเปเปอร์)
- **แถบการทำงาน (2.6.0):** แถบเล็ก ๆ ด้านล่างบอกว่าตารางโน้ตกำลังทำอะไร มีหลอดความคืบหน้าตอนส่งออก บันทึกภาพ เตรียมหน้าพิมพ์ หรือวาดวอลเปเปอร์ หลังแก้ไขจะขึ้น "รอบันทึกอัตโนมัติ…" นอกนั้นแสดงสิ่งที่ทำล่าสุดพร้อมเวลา และเวลาที่บันทึกล่าสุด ปุ่ม **ประวัติ** แสดงรายการล่าสุด (เปิดตาราง บันทึก แจ้งเตือน ย้อนกลับ ส่งออก คำเตือน เช่น "โปรแกรมไม่ตอบสนอง 3 วินาที ขณะบันทึก note.json") และเปิดโฟลเดอร์ที่มี `tablenote.log` ได้ กด ✕ เพื่อซ่อน เปิดคืนที่ **มุมมอง → แถบการทำงาน** (จำไว้ใน `settings.json`)
- **เลือกทั้งแถวและทั้งคอลัมน์ (2.6.0):** คลิกเลขแถวหรือหัวคอลัมน์เพื่อเลือกทั้งแถวหรือทั้งคอลัมน์ ลากหรือ Shift+คลิกเพื่อเลือกหลายอัน คลิกขวาเพื่อแทรกแถว (ด้านบน / ด้านล่าง) หรือคอลัมน์ (ซ้าย / ขวา) ตามจำนวนที่เลือก ลบ หรือ **แทรกที่คัดลอก** แถวที่คัดลอกจะมาพร้อมสีแถว การทำซ้ำ และการเตือนล่วงหน้า คอลัมน์ที่คัดลอกมาพร้อมชนิดและความกว้าง ข้อความจาก Excel แทรกเป็นแถวใหม่ ลาก ⋮⋮ ข้างเลขแถวเพื่อย้ายแถวที่เลือก ดับเบิลคลิกหัวคอลัมน์เพื่อเปลี่ยนชื่อ
- **วิธีใช้แบบหัวข้อ (2.6.0):** **ช่วยเหลือ → วิธีใช้** แสดงเป็นหัวข้อ คลิกเพื่อขยาย คลิกอีกครั้งเพื่อยุบ (มีปุ่มขยายทั้งหมด / ยุบทั้งหมด)
- **ช่องแบบ Excel (2.6.0):** คลิก = เลือกช่อง (สีทอง) ลากหรือกด Shift เพื่อคลุมหลายช่อง พิมพ์ = เขียนทับ ดับเบิลคลิกหรือ F2 = แก้ข้อความเดิม Delete = ล้าง Ctrl+C / Ctrl+X / Ctrl+V คัดลอก ตัด วาง ไป-มากับ Excel ได้ Ctrl+A หรือคลิกมุมซ้ายบน = เลือกทั้งหมด คลิกที่ว่างเพื่อยกเลิกการเลือก (ไม่มีจุด + สำหรับลากเติม)
- **แถบสูตร (2.6.0):** เหนือตาราง แสดงที่อยู่ช่องที่เลือก (B3) และข้อความทั้งหมด ไว้อ่านหรือแก้ข้อความยาว (ไม่คำนวณ)
- **ค้นหา (2.6.0):** Ctrl+F (หรือ **ตาราง → ค้นหา…**) ค้นข้อความในตาราง ทุกช่องที่เจอจะมีสีเหลือง Enter / Shift+Enter ไปช่องถัดไป / ก่อนหน้า
- **เสียงแจ้งเตือน (2.6.0):** **มุมมอง → ตั้งค่าระบบ → เสียงแจ้งเตือน…**: ปิดเสียง เลือกเสียงของ Windows หรือไฟล์ .wav ของเอง ตั้งความดัง (เกิน 50% จะถามยืนยัน) และทดลองฟัง
- **นับวัน (2.6.0):** **ตาราง → เพิ่มคอลัมน์นับวัน** แสดงในแต่ละแถวว่ารับงานมากี่วันแล้ว ("150 วัน") ตั้งสถานะเป็นเสร็จแล้วจะหยุดนับ ("42 วัน ✓") คลิกที่ช่องเพื่อดูวันรับงาน สถานะและตั้งแต่เมื่อไร อัปเดตล่าสุด และประวัติของแถวพร้อมวันที่และเวลา (เปลี่ยนสถานะ การแก้ไข และบันทึกความคืบหน้าที่พิมพ์ไว้) ดู [นับวัน](#นับวัน)
- **แถบเครื่องมือแถวเดียว (2.6.0):** + แถว, − แถว, + คอลัมน์, สี, ซ่อนงานเสร็จ, เรียงตามกำหนด, A− / 100% / A+, ส่งออก และ วอลเปเปอร์ ส่วนคัดลอก ส่งออกภาพ พิมพ์ ลบคอลัมน์ ภาษา วิธีใช้ และตั้งค่าระบบ (โหมดลอย ล็อกตำแหน่ง เปิดเมื่อเข้าสู่ระบบ ปิดเสียงเตือน) อยู่ในแถบเมนู
- ตารางแก้ไขได้ มีคอลัมน์เริ่มต้นคือ หัวข้อ, รายละเอียด, สถานะ, กำหนดส่ง และเปลี่ยนชื่อคอลัมน์ได้โดยไม่ทำให้การเตือนหยุดทำงาน (คอลัมน์กำหนดส่งลบไม่ได้)
- **ย้ายและลบคอลัมน์ (2.4.0):** ลากที่จับ ⋮⋮ บนหัวคอลัมน์ ใช้เมนูคลิกขวาที่หัวคอลัมน์ (ย้ายไปทางซ้าย/ขวา/ซ้ายสุด/ขวาสุด) หรือกด Alt+Shift+←/→ เมนูคลิกขวาก็ลบคอลัมน์ได้ โดยถามยืนยันทุกครั้ง (คอลัมน์กำหนดส่งลบไม่ได้) ย้อนด้วย Ctrl+Z
- **ย้ายแถว (2.4.0):** ลากเลขแถว ใช้เมนูคลิกขวาที่เลขแถว (เลื่อนขึ้น/ลง/ไปบนสุด/ไปล่างสุด) หรือกด Alt+Shift+↑/↓ เมื่อติ๊ก **ซ่อนงานเสร็จ** การย้ายจะข้ามแถวที่ซ่อน ย้อนด้วย Ctrl+Z
- **ตั้งค่าคอลัมน์ (2.4.0):** คลิกขวาที่หัวคอลัมน์แล้วเลือก **ตั้งค่าคอลัมน์…** เพื่อตั้งชื่อ ความกว้าง และชนิด (ข้อความ, ตัวเลข, ตัวเลือกแบบรายการ, ช่องทำเครื่องหมาย ✓) ตัวเลือกพิมพ์บรรทัดละหนึ่งรายการ การเปลี่ยนชนิดไม่แก้ข้อมูลในช่อง คอลัมน์สถานะและกำหนดส่งตั้งได้แค่ชื่อกับความกว้าง
- **สีและไฮไลต์แถว (2.4.0):** คลิกขวาที่เลขแถวเพื่อเลือกสี 8 สี (หรือไม่มีสี) เปิด/ปิดไฮไลต์ หรือล้างค่า สีตามแถวไปเมื่อย้ายหรือเรียง ย้อนด้วย Ctrl+Z และบันทึกทันที
- **กล่องแจ้งเตือน:** เมนู **ตาราง → เพิ่มกล่องแจ้งเตือน** เพิ่มกล่องที่มีหัวข้อและข้อความแก้ได้ ช่องกล่องแจ้งเตือนเหนือตารางขึ้นเมื่อมีกล่องเท่านั้น และปุ่ม **+ กล่องแจ้งเตือน** ในช่องนั้นเพิ่มกล่องต่อไป ปุ่มลบจะถามยืนยันก่อน (กล่องโต้ตอบเดียวกับตอนลบแถวหรือคอลัมน์) และกู้คืนไม่ได้ ลากที่จับ ⋮⋮ เพื่อเรียงลำดับ หรือใช้ปุ่ม **ขึ้น** / **ลง** (เข้าถึงด้วยคีย์บอร์ดได้ ไม่ต้องลาก) กล่องและลำดับบันทึกใน `note.json` แต่ละกล่องมีรหัสคงที่ คนละอย่างกับการเตือนตามกำหนดส่ง และ Ctrl+Z ไม่ย้อนการแก้กล่องนี้
- สถานะเลือกจากรายการ `ยังไม่เริ่ม` / `กำลังทำ` / `เสร็จแล้ว` แถวที่เสร็จจะขีดฆ่าและสีจาง
  - ถ้าพิมพ์เอง จะนับว่าเสร็จเฉพาะคำว่า `เสร็จ`, `เสร็จแล้ว`, `done`, `complete`, `completed`, `✓`, `✔` (ตรงทั้งคำ)
  - `ยังไม่เสร็จ` และ `ไม่เสร็จ` ไม่นับว่าเสร็จ
- ตั้งกำหนดส่งจากปฏิทินและช่องเวลา มีปุ่ม 📅 ตั้งเป็นอีก 1 นาทีเพื่อทดสอบ และกด Shift+คลิกเพื่อตั้งเป็นพรุ่งนี้ 09:00
- **เตือนล่วงหน้า ⏰ (ใหม่ใน 2.2.0)**
  - เลือกก่อน 15 นาที / 1 ชั่วโมง / 1 วัน หรือกำหนดเองเป็นนาที ชั่วโมง วัน (ไม่เกิน 30 วัน)
  - ได้สูงสุด 5 ครั้งต่องาน และยังเตือนตรงเวลาเสมอ
- งานทำซ้ำ `ทุกวัน` / `ทุกสัปดาห์` / `ทุกเดือน` เมื่อกดเสร็จ จะแทรกแถวรอบถัดไปให้เอง พร้อมค่าเตือนล่วงหน้าเดิม
- แจ้งเตือนทุกประมาณ 30 วินาที
  - ถ้าหลายงานถึงเวลาพร้อมกันจะรวมไว้ในหน้าต่างเดียว หน้าต่างไม่แย่งโฟกัส และปิดเสียงได้
  - ถ้าเตือนล่วงหน้าเด้งช้า (เช่น เพิ่งเปิดโปรแกรม) จะบอกเวลาที่เหลือจริง และ "พลาดการเตือนเมื่อ …" ถ้าหน้าต่างเตือนล่วงหน้าค้างไว้จนถึงกำหนด จะเปลี่ยนเป็นการเตือนครบกำหนด
  - แก้ค่าเตือนล่วงหน้าแล้ว การรับทราบเดิมยังอยู่ จะล้างเมื่อแก้กำหนดส่ง หรือเมื่อเปลี่ยนงานที่เสร็จแล้วกลับเป็นยังไม่เสร็จ (คำนวณการเตือนใหม่จากตอนนั้น)
  - ปุ่มของแต่ละงาน: **เลื่อน 10 นาที**, **เสร็จแล้ว**, **รับทราบ**
  - **ปิด** รับทราบทุกงานที่ค้าง
  - **X** เลื่อนงานที่ยังค้างไป 10 นาที
- สีแถวตามกำหนดส่ง: แดงคือเลยกำหนด เหลืองคือครบกำหนดวันนี้ (สีที่ผู้ใช้ตั้งในรุ่น 2.4.0 แสดงทับสีเหล่านี้)
- ซ่อนงานเสร็จ และเรียงตามกำหนดส่ง
- อ่านปี พ.ศ. ได้ เช่น `09/11/2569` จะแปลงเป็น ค.ศ. 2026 ให้เอง
- วันที่อ่านเป็น วัน/เดือน/ปี เสมอ เช่น `5/1/2026 9:00` คือ 5 มกราคม 2026 เวลา 09:00 ไม่ว่าเครื่องจะตั้งภาษาหรือปฏิทินแบบไหน
- วางจาก Excel และคัดลอกกลับไป Excel ได้
- ย้อนกลับด้วย Ctrl+Z และทำซ้ำด้วย Ctrl+Y ได้ 100 ขั้น
  - ย้อนได้: การพิมพ์ การแก้หัวคอลัมน์ การวาง การเพิ่ม/ลบแถวและคอลัมน์ การเปลี่ยนสถานะ กำหนดส่ง ค่าทำซ้ำ และค่าเตือนล่วงหน้า
  - ระหว่างพิมพ์ในช่อง Ctrl+Z จะย้อนตัวอักษรในช่องก่อน
- โหมดลอย โหมดวอลเปเปอร์ (Windows) ล็อกตำแหน่ง ไอคอนในถาดระบบ และเปิดเมื่อเข้าสู่ระบบ
- บันทึกอัตโนมัติหลังหยุดพิมพ์ประมาณ 1.5 วินาที
- หน้าต่างโปรแกรมเป็นภาษาอังกฤษเป็นค่าเริ่มต้น สลับเป็นไทยได้ที่เมนู **มุมมอง → ภาษา** (จำค่าไว้ใน `settings.json`)
- ขยาย/ย่อ 80–200% (ปุ่ม A− / 100% / A+, Ctrl +/−/0, Ctrl+ล้อเมาส์) ตั้งแต่ 2.6.0 ขยายเฉพาะกล่องแจ้งเตือนกับตาราง เมนูและแถบเครื่องมือขนาดเท่าเดิม
- ส่งออกตารางเป็น .xlsx, .csv หรือ .txt ได้ (ดู [การส่งออก](#การส่งออก))

### การเตือนทำงานต่อเนื่อง

- กดปิดหน้าต่างหลัก โปรแกรมจะย่อไปอยู่ที่ถาดไอคอน และยังเตือนต่อ (ถ้าสร้างไอคอนในถาดไม่ได้ การปิดหน้าต่างจะออกจากโปรแกรมจริง)
- ถ้าจะออกจริง ให้เลือก **ไฟล์ → ออกจากโปรแกรม** หรือคลิกขวาไอคอนในถาดแล้วเลือก **ออก** (ครั้งแรกจะมีข้อความบอก)
- ไอคอนแถบงานและถาด: ตอนแก้ไขตารางจะมีไอคอนทั้งที่แถบงาน (taskbar) และถาด ในโหมดวอลเปเปอร์เหลือไอคอนที่ถาดอย่างเดียว คลิกไอคอนที่ถาด เลือก **แก้ไขตาราง** ในเมนูถาด หรือกด Ctrl+Shift+E หน้าแก้ไข (และไอคอนบนแถบงาน) จะกลับมา ปิดแล้วเปิดใหม่ได้โหมดเดิม
- ถ้าเปิด **เปิดเมื่อเข้าสู่ระบบ** (รายการเริ่มระบบชื่อ `TableNote`) โปรแกรมจะเริ่มแบบซ่อนอยู่ในถาด (`--startup`) แต่ถ้าครั้งล่าสุดอยู่ในโหมดวอลเปเปอร์ จะวาดตารางบนวอลเปเปอร์ใหม่

## ดาวน์โหลดและติดตั้ง

1. ดาวน์โหลด `TableNote.exe` จาก [รุ่นล่าสุด](https://github.com/sevesghost/TableNote/releases/latest)
2. วางไฟล์ไว้ในโฟลเดอร์ที่ต้องการ แล้วดับเบิลคลิกเพื่อเปิด ไม่ต้องติดตั้ง
3. เปิด **มุมมอง → ตั้งค่าระบบ → เปิดเมื่อเข้าสู่ระบบ** เพื่อให้เตือนได้ตลอด

รองรับ Windows 10 และ Windows 11 แบบ 64 บิต `TableNote.exe` เป็นโฮสต์ .NET single-file พร้อมแอปที่บรรจุไว้ จึงไม่ต้องลง .NET เพิ่ม

## วิธีใช้เบื้องต้น

1. กด **+ แถว** หรือ F5 เพื่อเพิ่มงาน
2. พิมพ์ **หัวข้อ** และ **รายละเอียด**
3. เลือก **สถานะ**
4. ตั้ง **กำหนดส่ง** จากปฏิทินและช่องเวลา เลือก **ทำซ้ำ** ถ้าต้องการ และกด ⏰ เพื่อตั้งเตือนล่วงหน้า
5. เมื่อมีหน้าต่างเตือน ให้กด **เลื่อน 10 นาที**, **เสร็จแล้ว**, **รับทราบ**, **ปิด** (รับทราบทั้งหมด) หรือ **X** (เลื่อน 10 นาที)

ถ้าอยู่ในโหมดวอลเปเปอร์ กลับมาแก้ไขได้ 5 วิธี (วอลเปเปอร์เดิมจะกลับมาเอง):
- คลิกไอคอนตารางโน้ตที่ถาด
- เลือก **แก้ไขตาราง** จากเมนูในถาด
- กด Ctrl+Shift+E
- เปิดโปรแกรมอีกครั้ง
- เปิดด้วย `TableNote.exe --edit`

ดูวิธีใช้ในโปรแกรมได้จากเมนู **ช่วยเหลือ → วิธีใช้** หรือเมนู **วิธีใช้** ในถาด (บรรทัดแรกบอกรุ่น) และดูคู่มือฉบับเต็มได้ที่ [`docs/manual-th.md`](docs/manual-th.md)

## นับวัน

**ตาราง → เพิ่มคอลัมน์นับวัน** เพิ่มคอลัมน์ (ก่อนคอลัมน์สถานะ) ที่นับวันตั้งแต่วันรับงานของแต่ละแถว งานที่ยังไม่เสร็จเริ่มนับจากวันนี้ และแถวใหม่เริ่มนับตั้งแต่วันที่เพิ่ม หรือเปลี่ยนคอลัมน์ว่างเป็นคอลัมน์นับวันได้จาก **ตั้งค่าคอลัมน์… → ชนิด: นับวัน** ช่องแสดง "วันนี้", "1 วัน", "150 วัน" เมื่อตั้งสถานะเป็น **เสร็จแล้ว** จะหยุดนับและแสดงว่าใช้เวลากี่วัน ("42 วัน ✓")

คลิกช่องนับวัน (หรือกด Space) เพื่อเปิดหน้าต่างรายละเอียด:

- ค้างมากี่วัน (หรือใช้เวลากี่วัน) ตั้งแต่วันไหนถึงวันไหน
- **วันรับงาน**: เลือกวันอื่น หรือกด **วันนี้** (ย้อนได้ด้วย Ctrl+Z)
- สถานะและตั้งแต่เมื่อไร และอัปเดตล่าสุด ("8 วันที่แล้ว")
- ประวัติจากใหม่ไปเก่า: เปลี่ยนสถานะ แก้ข้อมูลในแถว และ **บันทึกความคืบหน้า** แต่ละรายการมีวันที่ เวลา และวันที่เท่าไรหลังรับงาน พิมพ์บันทึกแล้วกด Enter (หรือ **เพิ่มบันทึก**) เพื่อรายงานความคืบหน้า กด **แก้ไข** (หรือดับเบิลคลิกที่บันทึก) เพื่อแก้ข้อความ: Enter หรือ **บันทึก** = เก็บ, Esc หรือ **ยกเลิก** = คืนค่าเดิม บันทึกยังอยู่ที่วันเวลาเดิมและแสดงว่าแก้ไขเมื่อไร กด ✕ แล้ว **ลบ?** เพื่อลบบันทึก

ประวัติเริ่มเก็บตั้งแต่ตารางมีคอลัมน์นับวัน และบันทึกใน `note.json` (`rowHistory` ตามรหัสแถว ไม่เกิน 100 รายการต่อแถว) แก้ช่องเดิมภายใน 10 นาทีนับเป็นรายการเดียว และการพิมพ์ข้อมูลแรกของแถวใหม่ไม่ขึ้นในประวัติ (เปลี่ยนสถานะขึ้น) Ctrl+Z การแก้ไขจะบันทึกเป็นการเปลี่ยนแปลงอีกรายการ บันทึกความคืบหน้าไม่อยู่ใน Ctrl+Z ส่งออกและคัดลอกได้เป็นวันรับงาน (`yyyy-MM-dd`) ส่วนส่งออกภาพ พิมพ์ และวอลเปเปอร์แสดงเป็นจำนวนวัน

## ปฏิทิน

ปุ่ม **ปฏิทิน** บนแถบเครื่องมือ (หรือ F9, **ตาราง → ปฏิทิน…**, **ปฏิทิน** ในเมนูที่ถาด) เปิดปฏิทินทีละเดือน (6 สัปดาห์) ทุกแถวที่มีกำหนดส่งแสดงในวันของมัน พร้อมเวลาและหัวข้อ สีเหมือนในตาราง (แดงอ่อน = เลยกำหนด, เหลือง = ครบกำหนดวันนี้, จางและขีดฆ่า = เสร็จแล้ว หรือสีแถวที่ตั้งไว้) วันที่มีงานเกินช่องจะบอกว่า **+ อีก N** ชี้ที่วันหรือที่งานเพื่อดูรายละเอียด: สถานะ ทำซ้ำ เตือนล่วงหน้า เลขแถว และรายละเอียด รอบถัดไปของงานที่ทำซ้ำแสดงในวันของมันด้วย 🔁 (แถวของรอบถัดไปยังถูกเพิ่มเมื่อรอบก่อนเสร็จเหมือนเดิม) ปุ่ม ◀ ▶ หรือ PageUp / PageDown เปลี่ยนเดือน **วันนี้** หรือ Home กลับวันนี้ ลูกศรเลื่อนวันที่เลือก ด้านล่างมี **ซ่อนงานเสร็จ** และ **สัปดาห์เริ่มวัน** (อาทิตย์ หรือ จันทร์)

ปฏิทินไม่มีข้อมูลของตัวเอง งานในปฏิทินคือแถวของตาราง แก้ในตารางแล้วปฏิทินที่เปิดอยู่เปลี่ยนทันที และแก้ในปฏิทินก็คือแก้ในตาราง

**ตารางของวัน (ป๊อปอัพ)** คลิกวัน (หรือกด Enter) จะเปิดตารางของแถวที่กำหนดส่งวันนั้น มีคอลัมน์เหมือนตารางหลัก และช่อง **เวลา** (เว้นว่าง = ทั้งวัน):

- พิมพ์ในช่อง ตารางหลักเปลี่ยนทันที ย้อนได้ทีละขั้นด้วย Ctrl+Z (Ctrl+Z / Ctrl+Y ใช้ในปฏิทินและป๊อปอัพได้ด้วย) Enter = เก็บแล้วไปแถวถัดไป Esc = คืนค่าเดิม
- **+ แถว** เพิ่มแถวในตารางหลัก กำหนดส่งวันนั้นเวลา 09:00 (ถ้าเป็นวันนี้ใช้ชั่วโมงถัดไป) ใช้แถวว่างท้ายตารางก่อน ถ้าไม่มีจึงเพิ่มแถวใหม่ท้ายสุด
- **− แถว** ลบแถวที่เลือกออกจากตารางหลัก (ถามก่อนถ้ามีข้อมูล) **เอาวันที่ออก** เอาออกจากปฏิทินแต่แถวยังอยู่ในตาราง **ย้ายไปวันที่** ย้ายไปวันอื่นโดยเวลาคงเดิม
- สถานะ **⏰** เตือนล่วงหน้า และ **🔁** ทำซ้ำ ใช้เหมือนในตาราง (ตั้งเป็นเสร็จแล้วจะเพิ่มรอบถัดไป) การแจ้งเตือนทำงานเหมือนทุกแถว ถ้าตั้งเวลาที่ผ่านไปแล้วจากปฏิทิน จะไม่เด้งเตือน แต่แถวแสดงเป็นเลยกำหนดจนกว่าจะเสร็จ
- **↗** เปิดตารางหลักโดยเลือกแถวนั้นไว้ ส่วนทางกลับ: คลิกขวาเลขแถว → **ดูในปฏิทิน** เปิดปฏิทินที่วันของแถวนั้นและเลือกแถวไว้
- ◀ ▶ ด้านบนไปวันก่อนหน้า / วันถัดไป

**แถวที่เขียนไว้ก่อนมีปฏิทิน** ไม่ต้องย้ายข้อมูล ทุกแถวที่มีกำหนดส่งขึ้นในปฏิทินเอง (กด ◀ ▶ หรือ **ไปวันที่…** เพื่อดูเดือนอื่น) ส่วนแถวที่มีข้อมูลแต่ยังไม่มีกำหนดส่ง (หรืออ่านวันที่ไม่ได้) นับไว้ที่ปุ่ม **ใส่แถวเดิม… (N)** มุมขวาบนของปฏิทิน กดแล้วจะเห็นรายการพร้อมวันที่ที่เขียนไว้ในแถว — ในหัวข้อ ในคอลัมน์วันที่ หรือในข้อความ (`15/12/2569`, `2026-12-15`, `5 ม.ค. 2570 9.30 น.`, `Jan 5, 2026`) — ติ๊กแถวแล้วกดใส่ แถวจะไปอยู่วันที่ที่พบ หรือวันที่ที่เลือก (เวลาที่เลือก เว้นว่าง = ทั้งวัน) ย้อนได้ด้วย Ctrl+Z ครั้งเดียว รายการเดียวกันนี้เปิดได้จากตารางของวัน (**+ แถวเดิม…** ใส่ลงวันนั้น) และจากเมนูคลิกขวาเลขแถว (**ใส่ในปฏิทิน…** ติ๊กแถวนั้นไว้ให้) ถ้าตารางไม่มีคอลัมน์กำหนดส่ง ปฏิทินจะมีปุ่ม **เพิ่มคอลัมน์กำหนดส่ง**

**ปฏิทินบนวอลเปเปอร์** ด้านล่างของปฏิทิน (หรือ **มุมมอง → ปฏิทินบนวอลเปเปอร์**) เลือกได้ **ไม่แสดง**, **มุมขวาล่าง คู่กับตาราง** หรือ **มุมขวาล่าง เฉพาะปฏิทิน** เมื่อตารางอยู่บนวอลเปเปอร์ จะมีการ์ดปฏิทินที่มุมขวาล่างของจอ (เหนือแถบงาน) แสดงวันนี้ตัวใหญ่ เดือนนี้พร้อมจุดใต้วันที่มีงาน และงานที่เลยกำหนดหรือกำลังจะถึง วาดใหม่ตามตารางเสมอ เลือก **ถาด → ปฏิทิน** เพื่อเปิดปฏิทินโดยไม่ต้องออกจากวอลเปเปอร์

## โหมดวอลเปเปอร์

ปุ่ม **วอลเปเปอร์** บนแถบเครื่องมือ (หรือ **ไฟล์ → ตั้งเป็นวอลเปเปอร์**) ตั้งตารางเป็นวอลเปเปอร์ของ Windows:

- ภาพเต็มจอ วอลเปเปอร์เดิมของคุณยังอยู่ และมีการ์ดที่มีกล่องแจ้งเตือนกับตารางวางทับ ตรงตำแหน่งที่หน้าต่างแก้ไขอยู่ ขนาดไม่เกินหน้าต่างและตามขนาดที่ขยาย/ย่อไว้ แถวที่ไม่พอแสดงเป็น **+ อีก N แถว**
- เปลี่ยนเฉพาะจอที่หน้าต่างอยู่ ถ้าตั้งภาพแบบ **Span** (ภาพเดียวคร่อมทุกจอ) ตารางจะวาดคร่อมทุกจอ
- **ปฏิทินบนวอลเปเปอร์ (2.7.0):** ตั้งที่ **มุมมอง → ปฏิทินบนวอลเปเปอร์** (หรือ **บนวอลเปเปอร์** ในหน้าต่างปฏิทิน) จะมีการ์ดปฏิทินที่มุมขวาล่างของจอนั้น คู่กับตารางหรือเฉพาะปฏิทิน ดู [ปฏิทิน](#ปฏิทิน)
- หน้าแก้ไขไปอยู่ที่ถาด ภาพอัปเดตตามตาราง: งานที่กดเสร็จจากหน้าต่างเตือน งานที่เลยกำหนดหรือครบกำหนดวันนี้ และเมื่อขึ้นวันใหม่
- กลับมาแก้ไข: คลิกไอคอนที่ถาด เลือก **แก้ไขตาราง** ในเมนูถาด กด Ctrl+Shift+E หรือเปิดโปรแกรมอีกครั้ง วอลเปเปอร์เดิมจะกลับมาทันที เลือก **ออก** ในเมนูถาดก็คืนวอลเปเปอร์เดิมเหมือนกัน และเปิดครั้งหน้าจะวาดตารางกลับมา
- ตอนออกจากระบบ ถ้าเปิด **เปิดเมื่อเข้าสู่ระบบ** ไว้ ตารางยังอยู่บนวอลเปเปอร์และวาดใหม่ตอนเข้าระบบครั้งหน้า ถ้าไม่ได้เปิด จะคืนวอลเปเปอร์เดิม
- สไลด์โชว์จะเริ่มใหม่ตอนออกจากโหมดนี้ ส่วน **Windows spotlight** โปรแกรมเปิดกลับเองไม่ได้ จึงถามก่อน และตอนออกจะเหลือภาพ spotlight ของวันนั้นเป็นภาพนิ่ง (เปิด spotlight ใหม่ได้ที่ การตั้งค่า › การปรับแต่งให้เป็นแบบส่วนตัว › พื้นหลัง)
- ถ้าเปลี่ยนวอลเปเปอร์เองระหว่างที่ตารางอยู่บนวอลเปเปอร์ จะใช้ภาพใหม่ของคุณ และวาดตารางบนภาพนั้นแทน
- วอลเปเปอร์ที่องค์กรกำหนดไว้ (Group Policy) จะไม่ถูกเปลี่ยน
- ก่อนเปลี่ยนอะไร โปรแกรมเก็บสำเนาวอลเปเปอร์เดิมและข้อมูลที่ต้องคืนไว้ที่ `%LOCALAPPDATA%\TableNote\wallpaper\` (`wallpaper.json`, `original-*` และภาพตาราง `table-1.png` / `table-2.png`) ถ้าโปรแกรมปิดตัวผิดปกติ การเปิดครั้งถัดไปจะใช้ข้อมูลนี้ และ `TableNote.exe --edit` จะคืนวอลเปเปอร์เดิมแล้วเปิดหน้าแก้ไข

## การส่งออก

กด **ส่งออก** บนแถบเครื่องมือ (หรือ **ส่งออก…** ในเมนูถาด) เพื่อบันทึกตารางเป็น `.csv` (คั่นด้วยจุลภาค UTF-8 มี BOM), `.txt` (คั่นด้วยแท็บ UTF-8 มี BOM) หรือ `.xlsx`

**ไฟล์ส่งออกเปลี่ยนตามภาษาที่เลือก:** ป้ายสถานะ คอลัมน์ **ทำซ้ำ** และชื่อไฟล์เริ่มต้นจะเป็นภาษาที่เลือกในเมนู **มุมมอง → ภาษา** ตอนกดส่งออก โน้ตเดียวกันจึงได้ป้ายต่างกันเมื่อส่งออกคนละภาษา ส่วนชื่อคอลัมน์และข้อความที่ผู้ใช้พิมพ์จะส่งออกตามที่พิมพ์ และ `note.json` ไม่ถูกเปลี่ยน ถ้ามีโปรแกรมอื่นอ่านไฟล์นี้ ควรส่งออกด้วยภาษาเดิมทุกครั้ง

วันที่ส่งออกเป็น `yyyy-MM-dd` (หรือ `yyyy-MM-dd HH:mm` ถ้ามีเวลา) เป็น ค.ศ. เสมอทุกภาษา ตัวเลขใช้จุดทศนิยมเสมอ

**เลข 0 นำหน้า:** ใน `.csv` และ `.txt` ข้อความถูกเก็บตามที่พิมพ์ แต่ Excel จะตัด 0 นำหน้าทิ้งเมื่อเปิด CSV ตรง ๆ (`0812345678` กลายเป็น `812345678`) ถ้าต้องการเก็บไว้ ให้นำเข้าด้วย **ข้อมูล → จากข้อความ/CSV** แล้วตั้งคอลัมน์นั้นเป็น **ข้อความ** หรือส่งออกเป็น `.xlsx` แทน ใน `.xlsx` ค่าที่มี 0 นำหน้า มีเครื่องหมาย `+` มีเลขเกิน 15 หลัก หรือมีเลขหน้าจุดทศนิยมตั้งแต่ 12 หลัก (เช่น เลขบัตรประชาชน 13 หลัก) จะเก็บเป็นข้อความ ไม่สูญหาย

## ที่เก็บข้อมูล

- Windows: `%APPDATA%\TableNote\note.json`
- Linux: `~/.local/share/TableNote/note.json`
- ถ้าต้องการเก็บที่อื่น ให้ตั้งตัวแปร `TABLENOTE_DATA` เป็นพาธเต็มของไฟล์
- เลเยอร์และรูปภาพ (2.6.1.1): `layers.json` ข้าง `note.json` (เลเยอร์ ภาพวาดและรูปภาพในเลเยอร์ ค่าปากกา และภาพในช่อง เก็บไฟล์ก่อนหน้าเป็น `layers.json.prev`) และไฟล์รูปภาพในโฟลเดอร์ `images` ข้าง ๆ `note.json` และรูปแบบไฟล์ไม่เปลี่ยน สูงสุด 10 เลเยอร์ รูปภาพบนเลเยอร์ 100 ภาพ 400,000 จุด และภาพละไม่เกิน 20 MB
- โหมดวอลเปเปอร์ (Windows): `%LOCALAPPDATA%\TableNote\wallpaper\` หรือโฟลเดอร์ `wallpaper` ข้าง `note.json` เมื่อตั้ง `TABLENOTE_DATA`
- ปฏิทิน (2.7.0): ไม่มีข้อมูลของตัวเองใน `note.json` (งานในปฏิทินคือแถวที่มีกำหนดส่ง) ค่าที่ตั้งเก็บใน `settings.json`: `calendarWallpaper` (`corner` / `only`), `calendarWeekStart` (`1` = เริ่มวันจันทร์) และ `calendarHideDone` เขียนเฉพาะเมื่อไม่ใช่ค่าเริ่มต้น

ค่าเตือนล่วงหน้าเก็บในช่อง `reminders` ตามรหัสแถว ถ้ามีค่าผิดชนิด (เช่น `"offsets": ["15"]`) โปรแกรมจะทิ้งเฉพาะค่านั้น บันทึกลง `tablenote.log` ข้างไฟล์ `note.json` และเก็บตารางที่เหลือไว้ครบ

จากรุ่น 2.4.0 ไฟล์บันทึกเป็นรูปแบบรุ่น 5 และเพิ่ม `columnIds` (รหัสคอลัมน์คู่กับคอลัมน์), `columnSettings` (ชนิดและตัวเลือกของคอลัมน์ ตามรหัสคอลัมน์) และ `rowStyles` (สีและไฮไลต์แถว ตามรหัสแถว) ไฟล์เก่า (v2–v4) เปิดได้ตามปกติ การบันทึกครั้งแรกจะสำรองเป็น `note.vN.bak` (เช่น `note.v4.bak`) ไฟล์จากรุ่นใหม่กว่าจะไม่ถูกลดรุ่น และฟิลด์ที่ไม่รู้จักถูกเก็บไว้ ถ้ารุ่น 2.3.x เปิดไฟล์ v5 จะเปิดตารางได้ ไม่ปฏิเสธและไม่ลบฟิลด์ใหม่ (เก็บไว้แล้วเขียนกลับเมื่อบันทึก หลังสำรอง `note.v5.bak`) แต่จะยังไม่ใช้รหัสคอลัมน์ ตั้งค่าคอลัมน์ และสี/ไฮไลต์แถว

กล่องแจ้งเตือนเป็นอาร์เรย์ `alertBoxes` ที่ไม่บังคับ ของ `{ "id", "title", "text" }` ตามลำดับที่แสดง รุ่นของรูปแบบไฟล์ยังเป็น 5 ถ้าไม่มี `alertBoxes` หรือไม่ใช่อาร์เรย์ จะถือว่าไม่มีกล่อง รายการที่เสียถูกข้ามทีละรายการและบันทึกลง log ฟิลด์อื่นบนกล่อง (เผื่อสีต่อกล่องในภายหลัง) ถูกเขียนกลับ รุ่นที่ไม่รู้จักช่องนี้จะเก็บไว้เป็นฟิลด์ที่ไม่รู้จักแล้วเขียนกลับ

เปิดไฟล์จากรุ่นเก่าได้โดยข้อมูลไม่หาย และจะเตือนเฉพาะตรงเวลา ก่อนบันทึกเป็นรูปแบบ 2.2 ครั้งแรก โปรแกรมจะสำรองไฟล์เดิมตั้งชื่อตามรุ่นของไฟล์ คือ `note.v2.bak` สำหรับไฟล์รุ่น 1.x/2.0 และ `note.v3.bak` สำหรับไฟล์รุ่น 2.1.0 โดยไม่ทับไฟล์สำรองเดิม (ถ้าชื่อซ้ำจะเติมวันเวลาต่อท้าย) ถ้าไฟล์อ่านไม่ได้ โปรแกรมจะย้ายไฟล์เดิมไปเป็น `note.json.bak` แล้วเริ่มตารางใหม่ ถ้าตอนเปิดโปรแกรม `note.json` ถูกโปรแกรมอื่นใช้อยู่ (เช่น แอนติไวรัสหรือโปรแกรมแบ็กอัป) โปรแกรมจะแสดงตารางว่างชั่วคราว ไม่แตะ `note.json` และค่าเปิดเมื่อเข้าสู่ระบบ แล้วลองใหม่เรื่อยๆ จนอ่าน `note.json` ได้ก็เปิดให้ทันที สิ่งที่พิมพ์ลงตารางชั่วคราวจะถูกบันทึกลง `note.unsaved.json` แทน และการเปิดครั้งถัดไปจะเปลี่ยนชื่อไฟล์นั้นเป็น `note.unsaved-<วันเวลา>.json` (ไม่ถูกเขียนทับหรือลบ) พร้อมแจ้งให้ทราบ ถ้าไฟล์ใหญ่เกิน 8 MB หรือมีเกิน 1,000 แถว โปรแกรมจะสำรองไฟล์เต็มเป็น `note.overlimit-<วันเวลา>.bak` ก่อน แล้วเปิดตารางเท่าที่รองรับ (ถ้าเกินจำนวนแถว จะเปิด 1,000 แถวแรก) ถ้าการบันทึกจะทำให้ `note.json` ใหญ่เกิน 8 MB โปรแกรมจะไม่เขียนทับไฟล์ที่บันทึกล่าสุด และจะสำรองตารางตอนนี้ไว้ที่ `note.overlimit-<วันเวลา>.bak` จากรุ่น 2.3.0 จะเก็บ `note.json*.bak` ไว้แค่ 5 ไฟล์ล่าสุด (ไฟล์สำรองตามรุ่นและ `note.overlimit-*.bak` จะไม่ถูกลบเอง) ไฟล์ `tablenote.log` เขียนเป็นภาษาอังกฤษล้วน และจำกัดที่ 512 KB (2 ไฟล์ คือ `tablenote.log` และ `tablenote.1.log`)

ขีดจำกัด:
- ไม่เกิน 1,000 แถว
- 30 คอลัมน์ที่ผู้ใช้เพิ่มเอง
- ช่องละ 2,000 ตัวอักษร
- วางได้ครั้งละไม่เกิน 256 KB
- เตือนล่วงหน้าได้งานละ 5 ครั้ง
- ไฟล์ `note.json` ไม่เกิน 8 MB
- กล่องแจ้งเตือนไม่เกิน 30 กล่อง (หัวข้อ 200 ตัวอักษร ข้อความ 2,000 ตัวอักษร)

## การ build จากซอร์ส

ต้องมี .NET 10 SDK

```bash
git clone https://github.com/sevesghost/TableNote.git
dotnet restore
dotnet build -c Release
```

สร้างไฟล์ exe ไฟล์เดียวสำหรับ Windows x64 (ตัดโค้ดส่วนที่ไม่ได้ใช้ออก แปลงโค้ดเป็นภาษาเครื่องไว้ล่วงหน้า ไฟล์ราว 69 MB, zip ราว 29 MB ค่าที่ใช้อยู่ใน `TableNote.csproj` อธิบายไว้ใน [docs/performance.md](docs/performance.md))

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -o ./publish/win-x64
```

จะได้ไฟล์ `TableNote.exe` อยู่ใน `publish/win-x64`

โครงสร้างซอร์ส
- `Core/` โมเดลตาราง การบันทึก JSON การวางและคัดลอก Excel งานทำซ้ำ การคำนวณเวลาเตือน (`ReminderPlan.cs`) และการย้อนกลับ
- `Platform/` ส่วนของ Windows เช่น วอลเปเปอร์ (IDesktopWallpaper) ปุ่มลัด แถบงาน สัญญาณเปิดซ้ำ และการเปิดเมื่อเข้าสู่ระบบ
- `Services/` ระบบแจ้งเตือน หน้าต่างเตือน หน้าต่างตั้งเตือนล่วงหน้า และเสียง
- `MainWindow.axaml(.cs)` หน้าจอหลัก
