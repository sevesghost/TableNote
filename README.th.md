# ตารางโน้ต (TableNote)

โปรแกรมจดงานแบบตารางคล้าย Excel ขนาดเบา เตือนเมื่องานถึงกำหนดส่งและเตือนล่วงหน้าได้ สร้างด้วย Avalonia บน .NET 10

รุ่นล่าสุด: **2.4.2** (12 พฤศจิกายน 2026) หน้าต่างโปรแกรมเป็นภาษาอังกฤษเป็นค่าเริ่มต้น สลับเป็นไทยได้ด้วยปุ่ม **EN/TH** คู่มือภาษาอังกฤษอยู่ที่ [`docs/manual-en.md`](docs/manual-en.md)

## TableNote คืออะไร

TableNote เป็นตารางโน้ตเล็กๆ ที่วางไว้บนหน้าจอ ใช้จดงานและตั้งกำหนดส่ง เมื่อถึงเวลาหรือก่อนถึงเวลาตามที่ตั้งไว้ โปรแกรมจะเด้งหน้าต่างเตือนพร้อมเสียง ใช้ได้ทั้งแบบหน้าต่างลอยอยู่บนสุด และแบบติดอยู่กับพื้นโต๊ะของ Windows ข้อมูลบันทึกอัตโนมัติลงไฟล์ JSON ในเครื่อง ไม่ต้องใช้อินเทอร์เน็ต

## ความสามารถหลัก

- ตารางแก้ไขได้ มีคอลัมน์เริ่มต้นคือ หัวข้อ, รายละเอียด, สถานะ, กำหนดส่ง และเปลี่ยนชื่อคอลัมน์ได้โดยไม่ทำให้การเตือนหยุดทำงาน (คอลัมน์กำหนดส่งลบไม่ได้)
- **ย้ายและลบคอลัมน์ (2.4.0):** ลากที่จับ ⋮⋮ บนหัวคอลัมน์ ใช้เมนูคลิกขวาที่หัวคอลัมน์ (ย้ายไปทางซ้าย/ขวา/ซ้ายสุด/ขวาสุด) หรือกด Alt+Shift+←/→ เมนูคลิกขวาก็ลบคอลัมน์ได้ โดยถามยืนยันทุกครั้ง (คอลัมน์กำหนดส่งลบไม่ได้) ย้อนด้วย Ctrl+Z
- **ย้ายแถว (2.4.0):** ลากเลขแถว ใช้เมนูคลิกขวาที่เลขแถว (เลื่อนขึ้น/ลง/ไปบนสุด/ไปล่างสุด) หรือกด Alt+Shift+↑/↓ เมื่อติ๊ก **ซ่อนงานเสร็จ** การย้ายจะข้ามแถวที่ซ่อน ย้อนด้วย Ctrl+Z
- **ตั้งค่าคอลัมน์ (2.4.0):** คลิกขวาที่หัวคอลัมน์แล้วเลือก **ตั้งค่าคอลัมน์…** เพื่อตั้งชื่อ ความกว้าง และชนิด (ข้อความ, ตัวเลข, ตัวเลือกแบบรายการ, ช่องทำเครื่องหมาย ✓) ตัวเลือกพิมพ์บรรทัดละหนึ่งรายการ การเปลี่ยนชนิดไม่แก้ข้อมูลในช่อง คอลัมน์สถานะและกำหนดส่งตั้งได้แค่ชื่อกับความกว้าง
- **สีและไฮไลต์แถว (2.4.0):** คลิกขวาที่เลขแถวเพื่อเลือกสี 8 สี (หรือไม่มีสี) เปิด/ปิดไฮไลต์ หรือล้างค่า สีตามแถวไปเมื่อย้ายหรือเรียง ย้อนด้วย Ctrl+Z และบันทึกทันที
- สถานะเลือกจากรายการ `ยังไม่เริ่ม` / `กำลังทำ` / `เสร็จแล้ว` แถวที่เสร็จจะขีดฆ่าและสีจาง
  - ถ้าพิมพ์เอง จะนับว่าเสร็จเฉพาะคำว่า `เสร็จ`, `เสร็จแล้ว`, `done`, `complete`, `completed`, `✓`, `✔` (ตรงทั้งคำ)
  - `ยังไม่เสร็จ` และ `ไม่เสร็จ` ไม่นับว่าเสร็จ
- ตั้งกำหนดส่งจากปฏิทินและช่องเวลา มีปุ่ม 📅 ตั้งเป็นอีก 1 นาทีเพื่อทดสอบ และกด Shift+คลิกเพื่อตั้งเป็นพรุ่งนี้ 09:00
- **เตือนล่วงหน้า ⏰ (ใหม่ใน 2.2.0)**
  - เลือกก่อน 15 นาที / 1 ชั่วโมง / 1 วัน หรือกำหนดเองเป็นนาที ชั่วโมง วัน (ไม่เกิน 30 วัน)
  - ได้สูงสุด 5 ครั้งต่องาน และยังเตือนตรงเวลาเสมอ
- งานทำซ้ำ `ทุกวัน` / `ทุกสัปดาห์` / `ทุกเดือน` เมื่อกดเสร็จ จะแทรกแถวรอบถัดไปให้เอง พร้อมค่าเตือนล่วงหน้าเดิม
- แจ้งเตือนทุกประมาณ 30 วินาที
  - ถ้าหลายงานถึงเวลาพร้อมกันจะรวมไว้ในหน้าต่างเดียว หน้าต่างไม่แย่งโฟกัส และปิดเสียงได้
  - บน Windows มี toast แบบไม่มีเสียงที่มุมจอด้วย
  - ถ้าเตือนล่วงหน้าเด้งช้า (เช่น เพิ่งเปิดโปรแกรม) จะบอกเวลาที่เหลือจริง และ "พลาดการเตือนเมื่อ …" ถ้าหน้าต่างเตือนล่วงหน้าค้างไว้จนถึงกำหนด จะเปลี่ยนเป็นการเตือนครบกำหนด
  - แก้ค่าเตือนล่วงหน้าแล้ว การรับทราบเดิมยังอยู่ จะล้างเมื่อแก้กำหนดส่ง หรือเมื่อเปลี่ยนงานที่เสร็จแล้วกลับเป็นยังไม่เสร็จ (คำนวณการเตือนใหม่จากตอนนั้น)
  - ปุ่มของแต่ละงาน: **เลื่อน 10 นาที**, **เสร็จแล้ว**, **รับทราบ**
  - **ปิด** รับทราบทุกงานที่ค้าง
  - **X** เลื่อนงานที่ยังค้างไป 10 นาที
- สีแถวตามกำหนดส่ง: แดงคือเลยกำหนด เหลืองคือครบกำหนดวันนี้ (สีที่ผู้ใช้ตั้งในรุ่น 2.4.0 แสดงทับสีเหล่านี้)
- ซ่อนงานเสร็จ และเรียงตามกำหนดส่ง
- อ่านปี พ.ศ. ได้ เช่น `09/11/2569` จะแปลงเป็น ค.ศ. 2026 ให้เอง
- วันที่อ่านเป็น วัน/เดือน/ปี เสมอ เช่น `5/1/2026 9:00` คือ 5 มกราคม 2026 เวลา 09:00 ไม่ว่าเครื่องจะตั้งภาษาหรือปฏิทินแบบไหน
- วางจาก Excel และคัดลอกกลับไป Excel ได้
- ย้อนกลับด้วย Ctrl+Z และทำซ้ำด้วย Ctrl+Y ได้ 100 ขั้น
  - ย้อนได้: การพิมพ์ การแก้หัวคอลัมน์ การวาง การเพิ่ม/ลบแถวและคอลัมน์ การเปลี่ยนสถานะ กำหนดส่ง ค่าทำซ้ำ และค่าเตือนล่วงหน้า
  - ระหว่างพิมพ์ในช่อง Ctrl+Z จะย้อนตัวอักษรในช่องก่อน
- โหมดลอย โหมดวางแนบพื้นหลัง (Windows) ล็อกตำแหน่ง ไอคอนในถาดระบบ และเปิดเมื่อเข้าสู่ระบบ
- บันทึกอัตโนมัติหลังหยุดพิมพ์ประมาณ 1.5 วินาที
- หน้าต่างโปรแกรมเป็นภาษาอังกฤษเป็นค่าเริ่มต้น สลับเป็นไทยได้ด้วยปุ่ม **EN/TH** (จำค่าไว้ใน `settings.json`)
- ขยาย/ย่อ 80–200% (ปุ่ม A− / 100% / A+, Ctrl +/−/0, Ctrl+ล้อเมาส์)
- ส่งออกตารางเป็น .xlsx, .csv หรือ .txt ได้ (ดู [การส่งออก](#การส่งออก))

### การเตือนทำงานต่อเนื่อง

- กดปิดหน้าต่างหลัก โปรแกรมจะย่อไปอยู่ที่ถาดไอคอน และยังเตือนต่อ (ถ้าสร้างไอคอนในถาดไม่ได้ การปิดหน้าต่างจะออกจากโปรแกรมจริง)
- ถ้าจะออกจริง ให้คลิกขวาไอคอนในถาดแล้วเลือก **ออก** (ครั้งแรกจะมีข้อความบอก)
- ไอคอนแถบงานและถาด: ตอนแก้ไขตารางจะมีไอคอนทั้งที่แถบงาน (taskbar) และถาด ตอนวางแนบพื้นหลังจะเหลือไอคอนที่ถาดอย่างเดียว เลือก **แก้ไขตาราง** ในเมนูถาด กด Ctrl+Shift+E หรือเลิกแนบพื้นหลัง ไอคอนจะกลับมาที่แถบงาน ปิดแล้วเปิดใหม่ได้โหมดเดิม
- ถ้าติ๊ก **เปิดเมื่อเข้าสู่ระบบ** (รายการเริ่มระบบชื่อ `TableNote`) โปรแกรมจะเริ่มแบบซ่อนอยู่ในถาด (`--startup`) แต่ถ้าครั้งล่าสุดอยู่ในโหมดวางแนบพื้นหลัง จะเปิดกลับมาเป็นโหมดพื้นหลัง

## ดาวน์โหลดและติดตั้ง

1. ดาวน์โหลด `TableNote.exe` จาก [รุ่นล่าสุด](https://github.com/sevesghost/TableNote/releases/latest)
2. วางไฟล์ไว้ในโฟลเดอร์ที่ต้องการ แล้วดับเบิลคลิกเพื่อเปิด ไม่ต้องติดตั้ง
3. ติ๊ก **เปิดเมื่อเข้าสู่ระบบ** เพื่อให้เตือนได้ตลอด

รองรับ Windows 10 และ Windows 11 แบบ 64 บิต `TableNote.exe` เป็นโฮสต์ .NET single-file พร้อมแอปที่บรรจุไว้ จึงไม่ต้องลง .NET เพิ่ม

## วิธีใช้เบื้องต้น

1. กด **+ แถว** หรือ F5 เพื่อเพิ่มงาน
2. พิมพ์ **หัวข้อ** และ **รายละเอียด**
3. เลือก **สถานะ**
4. ตั้ง **กำหนดส่ง** จากปฏิทินและช่องเวลา เลือก **ทำซ้ำ** ถ้าต้องการ และกด ⏰ เพื่อตั้งเตือนล่วงหน้า
5. เมื่อมีหน้าต่างเตือน ให้กด **เลื่อน 10 นาที**, **เสร็จแล้ว**, **รับทราบ**, **ปิด** (รับทราบทั้งหมด) หรือ **X** (เลื่อน 10 นาที)

ถ้าอยู่ในโหมดวางแนบพื้นหลัง กลับมาแก้ไขได้ 4 วิธี:
- เลือก **แก้ไขตาราง** จากเมนูในถาด
- กด Ctrl+Shift+E
- เปิดโปรแกรมอีกครั้ง
- เปิดด้วย `TableNote.exe --edit`

ดูวิธีใช้ในโปรแกรมได้จากปุ่ม **?** บนแถบเครื่องมือ หรือเมนู **วิธีใช้** ในถาด (บรรทัดแรกบอกรุ่น) และดูคู่มือฉบับเต็มได้ที่ [`docs/manual-th.md`](docs/manual-th.md)

## การส่งออก

กด **ส่งออก** บนแถบเครื่องมือ (หรือ **ส่งออก…** ในเมนูถาด) เพื่อบันทึกตารางเป็น `.csv` (คั่นด้วยจุลภาค UTF-8 มี BOM), `.txt` (คั่นด้วยแท็บ UTF-8 มี BOM) หรือ `.xlsx`

**ไฟล์ส่งออกเปลี่ยนตามภาษาที่เลือก:** ป้ายสถานะ คอลัมน์ **ทำซ้ำ** และชื่อไฟล์เริ่มต้นจะเป็นภาษาที่เลือกด้วยปุ่ม **EN/TH** ตอนกดส่งออก โน้ตเดียวกันจึงได้ป้ายต่างกันเมื่อส่งออกคนละภาษา ส่วนชื่อคอลัมน์และข้อความที่ผู้ใช้พิมพ์จะส่งออกตามที่พิมพ์ และ `note.json` ไม่ถูกเปลี่ยน ถ้ามีโปรแกรมอื่นอ่านไฟล์นี้ ควรส่งออกด้วยภาษาเดิมทุกครั้ง

วันที่ส่งออกเป็น `yyyy-MM-dd` (หรือ `yyyy-MM-dd HH:mm` ถ้ามีเวลา) เป็น ค.ศ. เสมอทุกภาษา ตัวเลขใช้จุดทศนิยมเสมอ

**เลข 0 นำหน้า:** ใน `.csv` และ `.txt` ข้อความถูกเก็บตามที่พิมพ์ แต่ Excel จะตัด 0 นำหน้าทิ้งเมื่อเปิด CSV ตรง ๆ (`0812345678` กลายเป็น `812345678`) ถ้าต้องการเก็บไว้ ให้นำเข้าด้วย **ข้อมูล → จากข้อความ/CSV** แล้วตั้งคอลัมน์นั้นเป็น **ข้อความ** หรือส่งออกเป็น `.xlsx` แทน ใน `.xlsx` ค่าที่มี 0 นำหน้า มีเครื่องหมาย `+` มีเลขเกิน 15 หลัก หรือมีเลขหน้าจุดทศนิยมตั้งแต่ 12 หลัก (เช่น เลขบัตรประชาชน 13 หลัก) จะเก็บเป็นข้อความ ไม่สูญหาย

## ที่เก็บข้อมูล

- Windows: `%APPDATA%\TableNote\note.json`
- Linux: `~/.local/share/TableNote/note.json`
- ถ้าต้องการเก็บที่อื่น ให้ตั้งตัวแปร `TABLENOTE_DATA` เป็นพาธเต็มของไฟล์

ค่าเตือนล่วงหน้าเก็บในช่อง `reminders` ตามรหัสแถว ถ้ามีค่าผิดชนิด (เช่น `"offsets": ["15"]`) โปรแกรมจะทิ้งเฉพาะค่านั้น บันทึกลง `tablenote.log` ข้างไฟล์ `note.json` และเก็บตารางที่เหลือไว้ครบ

จากรุ่น 2.4.0 ไฟล์บันทึกเป็นรูปแบบรุ่น 5 และเพิ่ม `columnIds` (รหัสคอลัมน์คู่กับคอลัมน์), `columnSettings` (ชนิดและตัวเลือกของคอลัมน์ ตามรหัสคอลัมน์) และ `rowStyles` (สีและไฮไลต์แถว ตามรหัสแถว) ไฟล์เก่า (v2–v4) เปิดได้ตามปกติ การบันทึกครั้งแรกจะสำรองเป็น `note.vN.bak` (เช่น `note.v4.bak`) ไฟล์จากรุ่นใหม่กว่าจะไม่ถูกลดรุ่น และฟิลด์ที่ไม่รู้จักถูกเก็บไว้ ถ้ารุ่น 2.3.x เปิดไฟล์ v5 จะเปิดตารางได้ ไม่ปฏิเสธและไม่ลบฟิลด์ใหม่ (เก็บไว้แล้วเขียนกลับเมื่อบันทึก หลังสำรอง `note.v5.bak`) แต่จะยังไม่ใช้รหัสคอลัมน์ ตั้งค่าคอลัมน์ และสี/ไฮไลต์แถว

เปิดไฟล์จากรุ่นเก่าได้โดยข้อมูลไม่หาย และจะเตือนเฉพาะตรงเวลา ก่อนบันทึกเป็นรูปแบบ 2.2 ครั้งแรก โปรแกรมจะสำรองไฟล์เดิมตั้งชื่อตามรุ่นของไฟล์ คือ `note.v2.bak` สำหรับไฟล์รุ่น 1.x/2.0 และ `note.v3.bak` สำหรับไฟล์รุ่น 2.1.0 โดยไม่ทับไฟล์สำรองเดิม (ถ้าชื่อซ้ำจะเติมวันเวลาต่อท้าย) ถ้าไฟล์อ่านไม่ได้ โปรแกรมจะย้ายไฟล์เดิมไปเป็น `note.json.bak` แล้วเริ่มตารางใหม่ ถ้าไฟล์ใหญ่เกิน 8 MB หรือมีเกิน 1,000 แถว โปรแกรมจะสำรองไฟล์เต็มเป็น `note.overlimit-<วันเวลา>.bak` ก่อน แล้วเปิดตารางเท่าที่รองรับ (ถ้าเกินจำนวนแถว จะเปิด 1,000 แถวแรก) ถ้าการบันทึกจะทำให้ `note.json` ใหญ่เกิน 8 MB โปรแกรมจะไม่เขียนทับไฟล์ที่บันทึกล่าสุด และจะสำรองตารางตอนนี้ไว้ที่ `note.overlimit-<วันเวลา>.bak` จากรุ่น 2.3.0 จะเก็บ `note.json*.bak` ไว้แค่ 5 ไฟล์ล่าสุด (ไฟล์สำรองตามรุ่นและ `note.overlimit-*.bak` จะไม่ถูกลบเอง) ไฟล์ `tablenote.log` เขียนเป็นภาษาอังกฤษล้วน และจำกัดที่ 512 KB (2 ไฟล์ คือ `tablenote.log` และ `tablenote.1.log`)

ขีดจำกัด:
- ไม่เกิน 1,000 แถว
- 30 คอลัมน์ที่ผู้ใช้เพิ่มเอง
- ช่องละ 2,000 ตัวอักษร
- วางได้ครั้งละไม่เกิน 256 KB
- เตือนล่วงหน้าได้งานละ 5 ครั้ง
- ไฟล์ `note.json` ไม่เกิน 8 MB

## การ build จากซอร์ส

ต้องมี .NET 10 SDK

```bash
git clone https://github.com/sevesghost/TableNote.git
dotnet restore
dotnet build -c Release
```

สร้างไฟล์ exe ไฟล์เดียวสำหรับ Windows x64 (เมื่อใช้ `-r win-x64` โปรเจกต์จะใช้ `net10.0-windows10.0.19041.0` เพื่อให้ toast ใช้ได้)

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -o ./publish/win-x64
```

จะได้ไฟล์ `TableNote.exe` อยู่ใน `publish/win-x64`

โครงสร้างซอร์ส
- `Core/` โมเดลตาราง การบันทึก JSON การวางและคัดลอก Excel งานทำซ้ำ การคำนวณเวลาเตือน (`ReminderPlan.cs`) และการย้อนกลับ
- `Platform/` ส่วนของ Windows เช่น โหมดพื้นหลัง ปุ่มลัด ถาดระบบ และการเปิดเมื่อเข้าสู่ระบบ
- `Services/` ระบบแจ้งเตือน หน้าต่างเตือน หน้าต่างตั้งเตือนล่วงหน้า เสียง และ toast
- `MainWindow.axaml(.cs)` หน้าจอหลัก
- `Assets/` ฟอนต์ Noto Sans Thai และไอคอนถาด
